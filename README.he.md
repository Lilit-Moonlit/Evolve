# EVOLVE

**היכרויות, תכנון הריון ובריאות מאומתת — פרטיות כברירת מחדל, אמון בדיוק במקום שבו זה חשוב.**

EVOLVE היא פלטפורמת קוד פתוח מבוזרת, לאנשים שהתעייפו מלמסור את מספר הטלפון שלהם, את הפנים שלהם ואת נתוני הבריאות האינטימיים ביותר שלהם למסד נתונים של מישהו אחר. נכנסים עם ארנק הקריפטו שלכם — בלי טלפון, בלי דוא״ל, בלי KYC — ואפשר לשחזר את החשבון באמצעות התחייבות DNA בשרשרת. נתוני הבריאות שלכם נשארים שלכם: תוצאות בדיקות מנותחות אוטומטית, מצבו של כל פתוגן בנפרד **לעולם לא** מוצג לאף אחד, וההתאמה מסתמכת רק על פסקי תאימות אנונימיים (Safe / Compatible / Caution / Risk). הצ׳אט פועל עמית-אל-עמית דרך libp2p ו-Nostr, עם גיבוי HTTP לנוחות.

> **סטטוס — הפלטפורמה עובדת היום; מיינטנט ו-DEX הם הצעד הבא.**
> היכרויות, תכנון הריון, אימות בריאות, זרימת המעבדה, צ׳אט P2P, טוקן EVOLVE וממשל — כולם פועלים. עדיין לפנינו: **פריסה במיינטנט ונזילות DEX**, וכן **מכירה ציבורית מתוכננת** (ראו [טוקן EVOLVE](#טוקן-evolve-טסטנט-בלבד)).
> חוזים חכמים פרוסים **בטסטנט Sepolia של Ethereum בלבד**. שום דבר כאן אינו ייעוץ פיננסי או הצעת השקעה.

> **EVOLVE שימושי בשבילכם? תמכו בפיתוח — כל תרומה הולכת לקוד, לשותפויות מעבדה, לאירוח ולתרגום → [DONATE.md](DONATE.md).**

## מה ולמה

אפליקציות היכרויות מסורתיות מבקשות מכם להחליף את מספר הטלפון, הדוא״ל, התמונות ופרטי הבריאות האינטימיים במסד נתונים מרכזי — ואז לסמוך על אותו מסד נתונים לנצח. EVOLVE מתחיל מההנחה ההפוכה: **פרטיות כברירת מחדל, משמורת עצמית ובלי נקודת כשל יחידה**.

- **פרטיות כברירת מחדל** — נתוני בריאות לעולם לא נחשפים; רק פסקים אנונימיים.
- **עמידות לחסימות** — קודם כל הודעות P2P, אחסון מבוזר, עיצוב רב-רשתי, בלי דומיינים מוטמעים.
- **זהות במשמורת עצמית** — הארנק שלכם הוא הכניסה; שחזור מבוסס DNA במקום דוא״ל או טלפון.
- **בלי מחסום KYC** — לא נדרשים תעודת זהות ממשלתית, טלפון או דוא״ל כדי להשתמש בפלטפורמה.

את ההנמקה המלאה קראו ב-[docs/WHAT-AND-WHY.md](docs/WHAT-AND-WHY.md).

## בריאות שאפשר באמת לסמוך עליה

- מעלים בדיקת מחלות מין (STD) כטקסט גולמי או PDF (חילוץ שכבת טקסט, עם גיבוי OCR לסריקות).
- המנתח מכיר 8 פתוגנים: HIV-1/2, עגבת, כלמידיה, זיבה, HSV-1, HSV-2, הפטיטיס B, הפטיטיס C — בפורמטים של דוחות באנגלית, באוקראינית וברוסית.
- **מצב של פתוגן בודד לעולם לא מוצג למשתמשים אחרים.** פרופילים מציגים רק את הפסק האנונימי: **Safe / Compatible / Caution / Risk**.
- רשומות DNA בשרשרת (`DNAVerification.sol`) מאפשרות שחזור ואימות.

### מעבדות שותפות — הוכחות, לא הבטחות

נכנסים למעבדה שותפה ומציגים את קוד ה-QR. המעבדה סורקת אותו, מאשרת את הזהות שלכם באמצעות **התאמת פנים** (כדי שאף אחד אחר לא יוכל לאסוף את התוצאה שלכם) ומצרפת את דוח ה-STD — PDF, סריקה או טקסט, ואפילו OCR גרוע. התוצאה חתומה על ידי מעבדה אמיתית, לא על ידיכם, כך שאחרים רואים **עובדה מאומתת** במקום המילה שלכם. וכל אימות מאושר משלם **1 EVOLVE למטופל ו-1 EVOLVE למעבדה** — לשני הצדדים יש סיבה להיות כנים. פתוגנים בודדים עדיין לעולם לא מוצגים לאף אחד.

## מציאת בן/בת זוג

- מסנני חיפוש: "מה אתם מחפשים" (היכרויות / תכנון הריון / תכנון הריון פוליאנדרי / בדיקות STD), "את מי אתם מחפשים" (גברים, נשים, זוגות), בחירות קסקדה ממדינה לעיר, "יכול/ה להגיע למדינה שלכם" עם רשימות לפי מדינה, גוון עור, העדפת בדיקות, רק STD-תואמים.
- אשף הצטרפות: גיל (ניתן להסתיר), שפות, ביו, תמונה.
- **צ׳אט P2P** על libp2p (gossipsub) + Nostr, עם גיבוי HTTP API.

## תכנון הריון

שתי דרכים לתכנן ילד, ושתיהן נשענות על אותו רעיון: כוונה אמיתית מודגמת בהשקעה אמיתית ב-EVOLVE — לעולם לא בהבטחות. המחויבות של גבר חיה בהפקדון ה-EvolveFund שלו (החל מ-15 EVOLVE, נעול לפחות 30 יום), ואישה יכולה לקבוע את סף ההפקדה המינימלי שלה לגברים שמגיעים אליה.

**תכנון הריון.** האישה מובילה: היא מזמינה גבר מסוים ומציינת אותו בקשר (bond). הוא צריך הפקדון EvolveFund פעיל; כששניהם מאשרים, ההפקדון ננעל והספירה לאחור מתחילה. הריון מדווח בין 14 ל-30 יום לאחר האישור, ובדיקות ה-STD וה-DNA של בני הזוג נלקחות במפגש עצמו — תוצאות מחלות מין עדכניות חשובות, DNA אינו מזדקן. ברגע שהאבהות מאושרת, הפקדון הגבר עובר לאישה; אם לא מאושרת, ההפקדון פשוט משוחרר חזרה אליו. שום דבר לא מחליף ידיים עד שהעובדות מוסדרות.

**תכנון הריון פוליאנדרי.** הבחירה שייכת לה, ונשארת פרטית. היא פותחת מושב שרץ 48 שעות — בלי הפקדון משלה (היא רשאית להוסיף אחד רק למען המוניטין, אם תרצה). גברים עם הפקדון פעיל יכולים להצטרף — עד 50 — ולאשר, מה שנועל את ערבותם. ארבעה עשר ימים לאחר סגירת המושב נבחר האב. הוא מקבל את הפקדונו בחזרה בתוספת תגמול מהמאגר: פי שניים מההפקדון שלו ו-1 EVOLVE עבור כל משתתף אחר. הגברים שלא נבחרו מפסידים את ערבותם — 90% לאישה, 10% לאב שנבחר. היא לא מסכנת דבר ויכולה רק להרוויח; הגברים שמים את ערבותם מאחורי הזכות להיבחר.

## טוקן EVOLVE (טסטנט בלבד)

- ERC-20, היצע מקסימלי **8,000,000,000 EVOLVE**. פעולות מנהל כלואות מאחורי `TimelockController` של 48 שעות.
- **הקצאת היצע מתוכננת** — מתוכננת כך שכמעט כל ההיצע יעבוד עבור המשתמשים, לא עבור אנשי פנים:

| מטרה                                         |        EVOLVE |
| -------------------------------------------- | ------------: |
| מייסדים וצוות (משכורת / תגמול)               |    25,000,000 |
| רזרבת DEX (עתיד)                             |     4,000,000 |
| מכירה ציבורית (מתוכננת)                      |     5,000,000 |
| רזרבת תגמולים — מעבדות, מטופלים, אמהות, אבות | 7,966,000,000 |

- **מכירה ציבורית מתוכננת** — 5,000,000 EVOLVE יימכרו על ידי האפליקציה במחיר **$0.8 ליחידה**, בתשלום בכל טוקן שהאפליקציה תומכת בו; התמורה מממנת פיתוח. _(מתוכנן — עדיין לא פעיל.)_
- **פליטה ללא צורך באמון (מתוכננת)** — רזרבת התגמולים של ~7,966,000,000 אמורה להינעל ב-`RewardVault` שאי אפשר לרוקן: היא תשוחרר בהדרגה בלבד דרך תגמולים למעבדות, למטופלים, לאמהות ולאבות, ושינויי כללים ידרשו הצבעת ממשל. אפילו המייסד לא יוכל למשוך ממנה. עיצוב: [docs/REWARD-VAULT-PLAN.md](docs/REWARD-VAULT-PLAN.md).
- **כלכלת מתנות אימוג׳י** — מתנה עולה 1 EVOLVE, ומחולקת יחסית בין בעלי המתנות הקיימים; מודל הכנסה מתמשך, ומתנות ניתנות להעברה.
- **EvolveFund** — סטייקינג לגברים (מינימום 15 EVOLVE, נעילה של 30 יום) שנכלל במשקל הממשל; נשים משתמשות ביתרת הארנק.
- **תגמולי אימות** — 1 EVOLVE למשתמש המאומת ו-1 EVOLVE למעבדה המאשרת לכל אימות STD/DNA (בתוספת ברז מוגבל-קצב).
- **ממשל** — משקל ההצבעה משלב מוניטין רקורסיבי (8 הצבעות, עומק 3), נתח ילדים/אבהות, ו-EVOLVE מושקע או מוחזק.
- אינטגרציית **LayerZero OFT** להעברות EVOLVE רב-שרשרתיות בעתיד (התלויות במקום; מעבר ל-Sepolia שום דבר עדיין לא נפרס).

## ארכיטקטורה ומחסנית טכנולוגיות

מונורפו המנוהל עם npm workspaces + Turborepo:

```
apps/
  web/          # Vite + React + TypeScript (main web app, i18next, Prisma)
  mobile/       # Expo + React Native
packages/
  config/       # Feature flags & dynamic remote configuration
  contracts/    # Solidity 0.8.24, Hardhat, Ignition, OpenZeppelin, LayerZero
  core/         # Shared types, utilities, middleware, web3
  matching/     # Matching algorithms, filters, ranking
  p2p/          # libp2p (gossipsub) + Nostr networking
  storage/      # IPFS, Arweave, Lit Protocol
docs/           # Architecture, tokenomics, roadmap, FAQ
```

חוזים חכמים מרכזיים: `EVOLVE.sol` (ERC-20), `ProfileNFT.sol` (ERC-721), `TrustScore.sol`, `Voting.sol`, `Evolve2Earn.sol` (מתנות אימוג׳י + תגמולים), `Governance.sol`, `BondManager.sol` (תכנון הריון ותכנון הריון פוליאנדרי), `EvolveFund.sol`, `VerificationRegistry.sol`, `DNAVerification.sol`, ERC-4337 `SmartAccountFactory` + `Paymaster`, ו-`TimelockController` של OpenZeppelin.

פרטים: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) · [docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md) · [docs/TOKENOMICS.md](docs/TOKENOMICS.md)

## מתחילים (מפתחים)

דרישות: **Node.js 20+** ו-npm 10.x.

```bash
# Clone and install all workspaces
git clone https://github.com/Lilit-Moonlit/Evolve.git
cd Evolve
npm install

# Web app (Vite dev server on http://localhost:3000)
cd apps/web
npm run dev
npm test                # vitest suite

# Smart contracts
cd packages/contracts
npm run compile         # hardhat compile
npm test                # hardhat test suite
npm run deploy:local    # deploy all contracts to an in-process Hardhat network
```
