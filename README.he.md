# EVOLVE

**היכרויות, תכנון הריון ובריאות מאומתת — פרטיות כברירת מחדל, אמון בדיוק במקום שבו זה חשוב.**

EVOLVE היא פלטפורמה מבוזרת בקוד פתוח, לאנשים שנמאס להם למסור את מספר הטלפון שלהם, את הפנים שלהם ואת נתוני הבריאות האינטימיים ביותר שלהם למסד נתונים של מישהו אחר. נכנסים עם ארנק הקריפטו שלכם — בלי טלפון, בלי דוא״ל, בלי KYC — ואפשר לשחזר את החשבון באמצעות התחייבות DNA על השרשרת. נתוני הבריאות שלכם נשארים שלכם: תוצאות הבדיקות מנותחות אוטומטית, מצבו של כל פתוגן בנפרד **לעולם לא** מוצג לאף אחד, וההתאמה מסתמכת רק על פסקי תאימות אנונימיים (Safe / Compatible / Caution / Risk). הצ׳אט פועל עמית-אל-עמית (P2P) דרך libp2p ו-Nostr, עם גיבוי HTTP לנוחות. מתנות והעברות צועדות לקראת סודיות מלאה: כיום כבר פועלות מתנות השומרות על פרטיות השולח, ובמפת הדרכים נמצאים ארנק מוגן של Railgun ואבטיפוס zero-knowledge של Aztec (ראו [פרטיות והעברות סודיות](#פרטיות-והעברות-סודיות)).

> **סטטוס — מצב הדגמה, בפיתוח פעיל.**
> היכרויות, תכנון הריון, אימות בריאות, זרימת המעבדה, צ׳אט P2P, הטוקן EVOLVE והממשל — כולם ממומשים ופועלים ב**הדגמה מקומית** — האפליקציה **טרם נפרסה לציבור**. עוד לפנינו: **פריסה ב-mainnet ונזילות DEX**, ובנוסף **מכירה ציבורית מתוכננת** (ראו [הטוקן EVOLVE](#הטוקן-evolve-ברשת-בדיקה-בלבד)).
> חוזים חכמים פרוסים **ברשת הבדיקה Ethereum Sepolia בלבד**. שום דבר כאן אינו מהווה ייעוץ פיננסי או הצעת השקעה.

> **EVOLVE שימושי בשבילכם? תמכו בפיתוח — כל תרומה הולכת לקוד, לשותפויות עם מעבדות, לאירוח ולתרגום ← [DONATE.md](DONATE.md).**

## מה ולמה

אפליקציות היכרויות מסורתיות מבקשות מכם להחליף את מספר הטלפון, הדוא״ל, התמונות ופרטי הבריאות האינטימיים שלכם במסד נתונים מרכזי — ואז לסמוך על אותו מסד נתונים לנצח. EVOLVE מתחיל מההנחה ההפוכה: **פרטיות כברירת מחדל, משמורת עצמית, ובלי נקודת כשל יחידה**.

- **פרטיות כברירת מחדל** — נתוני בריאות לעולם לא נחשפים; רק פסקי תוצאה אנונימיים.
- **עמידות בפני חסימות** — מסרים P2P תחילה, אחסון מבוזר, עיצוב רב-רשתי, בלי דומיינים מוטמעים בקוד.
- **זהות במשמורת עצמית** — הארנק שלכם הוא הכניסה שלכם; שחזור מבוסס DNA במקום דוא״ל או טלפון.
- **בלי שער KYC** — לא נדרשים תעודת זהות ממשלתית, טלפון או דוא״ל כדי להשתמש בפלטפורמה.

את הנימוק המלא קראו ב-[docs/WHAT-AND-WHY.md](docs/WHAT-AND-WHY.md).

## בריאות שאפשר באמת לסמוך עליה

- העלאת בדיקת STD כטקסט גולמי או כ-PDF (חילוץ משכבת הטקסט, עם גיבוי OCR לסריקות).
- המנתח מכיר 8 פתוגנים: HIV-1/2, עגבת, כלמידיה, זיבה, HSV-1, HSV-2, הפטיטיס B, הפטיטיס C — בפורמטים של דוחות באנגלית, באוקראינית וברוסית.
- **מצב של פתוגן בודד לעולם לא מוצג למשתמשים אחרים.** בפרופילים מוצג תמיד רק פסק התוצאה האנונימי: **Safe / Compatible / Caution / Risk**.
- רשומות DNA על השרשרת (`DNAVerification.sol`) מניעות שחזור ואימות.

### מעבדות שותפות — הוכחות, לא הבטחות

נכנסים למעבדה שותפה ומציגים את קוד ה-QR שלכם. המעבדה סורקת אותו, מאשרת את זהותכם באמצעות **התאמת פנים** (כדי שאף אחד אחר לא יוכל לאסוף את התוצאה שלכם) ומצרפת את דוח ה-STD — PDF, סריקה או טקסט, ואפילו OCR גרוע. התוצאה חתומה על ידי מעבדה אמיתית, לא על ידיכם, ולכן אחרים רואים **עובדה מאומתת** במקום את המילה שלכם. וכל אימות שמאושר משלם **1 EVOLVE למטופל ו-1 EVOLVE למעבדה** — לשני הצדדים יש סיבה להיות הגונים. מצבם של פתוגנים בודדים, כתמיד, לעולם לא מוצג לאף אחד.

## מציאת בן או בת זוג

- מסנני חיפוש: "מה אתם מחפשים" (היכרויות / תכנון הריון / תכנון הריון פוליאנדרי / בדיקות STD), "את מי אתם מחפשים" (גברים, נשים, זוגות), בחירה מדורגת מדינה ← עיר, "יכול להגיע למדינה שלכם" עם רשימות לכל מדינה, גוון עור, העדפת בדיקות, תואמי STD בלבד.
- אשף הרשמה: גיל (ניתן להסתרה), שפות, ביוגרפיה, תמונה.
- **צ׳אט P2P** דרך libp2p (gossipsub) + Nostr, עם גיבוי HTTP API.

## תכנון הריון

שתי דרכים לתכנן ילד, ושתיהן נשענות על אותו רעיון: כוונה אמיתית מוכחת בעירבון אמיתי ב-EVOLVE — לעולם לא בהבטחות. המחויבות של הגבר חיה בהפקדת ה-EvolveFund שלו (החל מ-15 EVOLVE, נעולה לפחות ל-30 יום), ואישה יכולה לקבוע לעצמה הפקדה מינימלית לגברים שמגיעים אליה.

**תכנון הריון.** האישה מובילה: היא מזמינה גבר מסוים ורושמת אותו בקשר (bond). הוא זקוק להפקדת EvolveFund פעילה; כששני הצדדים מאשרים, ההפקדה ננעלת וספירת הזמן מתחילה. הריון מדווח בין 14 ל-30 יום לאחר האישור, ובדיקות ה-STD וה-DNA של בני הזוג נלקחות בפגישה עצמה — תוצאות STD עדכניות חשובות, DNA לא מזדקן. ברגע שהאבהות מאושרת, הפקדת הגבר עוברת לאישה; אם היא לא מאושרת, ההפקדה פשוט משוחררת חזרה אליו. שום דבר לא עובר מיד ליד עד שהעובדות מוכרעות.

**תכנון הריון פוליאנדרי.** הבחירה שייכת לה ונשארת פרטית. היא פותחת מפגש שנמשך 48 שעות — בלי הפקדה משלה (היא רשאית להוסיף אחת למען המוניטין בלבד, אם תרצה). גברים בעלי הפקדה פעילה רשאים להצטרף — עד 50 — ולאשר, והאישור נועל את עירבונם. ארבעה עשר ימים לאחר סגירת המפגש נבחר האב. הוא מקבל את הפקדתו בחזרה ובנוסף תגמול מהמאגר: פי שניים מהפקדתו ו-1 EVOLVE על כל אחד מהמשתתפים האחרים. הגברים שלא נבחרו מפסידים את עירבונם — 90% לאישה, 10% לאב הנבחר. היא אינה מסכנת דבר ויכולה רק להרוויח; הגברים מעמידים את עירבונם מאחורי הזכות להיבחר.

## פרטיות והעברות סודיות

פרטיות היא ברירת המחדל — ו-EVOLVE בונה מפת דרכים לקראת העברות סודיות לחלוטין על השרשרת.

- **מתנות פרטיות** — שלחו ורד 🌹 או קקטוס 🌵 (1 EVOLVE) ובחרו מי יוכל לראות שאתם השולח: _פומבי_, _אנונימי לכולם פרט למקבל/ת_, או _אנונימי לחלוטין_. במצבים האנונימיים המתנה נשלחת כשובר חד-פעמי שהמקבל/ת פודה בארנק שלו/שלה, וכך השולח לעולם אינו מופיע על השרשרת. (אנונימיות השולח כיום היא בסיסית: את עסקת המימון ניתן לתאם לפי זמן וסכום.)
- **ארנק מוגן של Railgun** — ארנק פרטי מאחורי דגל תכונה (`VITE_RAILGUN_ENABLED`, כבוי כברירת מחדל) שמסתיר סכומים וכתובות באמצעות הבריכה החיה של Railgun ל-zero-knowledge. זו הדרך לאנונימיות אמיתית של השולח.
- **אבטיפוס Aztec** — אותה לוגיקה של העברות פרטיות וקשרים פרטיים, מנוסחת כמעגלי Noir מסוג zero-knowledge ומוחזקת מאחורי שער מפורש עד ש-Aztec תהיה מוכנה לסביבת ייצור. ראו [docs/AZTEC-PROTOTYPE.md](docs/AZTEC-PROTOTYPE.md).
- **מודל שני הארנקים** — ארנק עירבון פומבי משתתף בממשל; ארנק פרטי מוגן **מוחרג** בכוונה ממשקל הממשל, כדי להפריד בין פרטיות לבין כוח הצבעה.

פרטים: [docs/RAILGUN-INTEGRATION.md](docs/RAILGUN-INTEGRATION.md) · [docs/SHIELDED-STAKES-DESIGN.md](docs/SHIELDED-STAKES-DESIGN.md) · [docs/AZTEC-PROTOTYPE.md](docs/AZTEC-PROTOTYPE.md).

```
  core/         # Shared types, utilities, middleware, web3
  matching/     # Matching algorithms, filters, ranking
  p2p/          # libp2p (gossipsub) + Nostr networking
  storage/      # IPFS, Arweave, Lit Protocol
docs/           # Architecture, tokenomics, roadmap, FAQ
```

חוזים חכמים עיקריים: `EVOLVE.sol` (ERC-20), `ProfileNFT.sol` (ERC-721), `TrustScore.sol`, `Voting.sol`, `Evolve2Earn.sol` (מתנות אימוג׳י + תגמולים), `Governance.sol`, `BondManager.sol` (תכנון הריון ותכנון הריון פוליאנדרי), `EvolveFund.sol`, `VerificationRegistry.sol`, `DNAVerification.sol`, ERC-4337 `SmartAccountFactory` + `Paymaster`, ו-`TimelockController` של OpenZeppelin.

פרטים: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) · [docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md) · [docs/TOKENOMICS.md](docs/TOKENOMICS.md)

## מפת דרכים

בעיצומו: הכשרת אפליקציית הווב לקראת ייצור. מתוכנן: רישום מעבדות והסמכת בדיקות על השרשרת, מתאם אמיתי מול ספקי דואר לקליטת דוחות מעבדה, תעודות מאומתות על השרשרת בפרופילים, **RewardVault נטול-האמון** עם פליטה מוגנת-ממשל ([עיצוב](docs/REWARD-VAULT-PLAN.md)), **מכירת הטוקנים הציבורית**, עדכון ה-vesting להקצאת המייסדים, ואספקת נזילות DEX (כרגע חסום — הדבר דורש פריסות טוקן ב-mainnet). בצד הפרטיות, מתנות פרטיות-שולח הושלמו, ואילו ארנק Railgun המוגן והגירת הקשרים הפרטיים של Aztec נשארים מאחורי הבדיקות שב-[docs/ROADMAP.md](docs/ROADMAP.md) וב-[docs/AZTEC-PROTOTYPE.md](docs/AZTEC-PROTOTYPE.md). הרחבה רב-רשתית (Arbitrum, Avalanche ושרשרות EVM נוספות) תגיע לאחר חיזוק רשת הבדיקה.

הרשימה המלאה: [docs/ROADMAP.md](docs/ROADMAP.md).

## איך מתחילים (למפתחים)

דרישות: **Node.js 20+** ו-npm 10.x.

```bash
# Clone and install all workspaces
git clone https://github.com/Lilit-Moonlit/Evolve.git
cd Evolve
npm install

# Web app (Vite dev server on http://localhost:3000)
cd apps/web
npm run dev
npm test                # vitest suite

# Smart contracts
cd packages/contracts
npm run compile         # hardhat compile
npm test                # hardhat test suite
npm run deploy:local    # deploy all contracts to an in-process Hardhat network
```
