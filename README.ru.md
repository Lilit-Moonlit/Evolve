# EVOLVE

**Знакомства, зачатие и подтверждение здоровья — приватность по умолчанию, проверенность там, где это важно.**

EVOLVE — открытая децентрализованная платформа для проверяемых интимных связей: знакомства, зачатие и анонимная совместимость по STD/DNA. Вы входите со своим криптокошельком (Sign-In with Ethereum) — без номера телефона, без электронной почты, без KYC — и можете восстановить аккаунт через ончейн-обязательство DNA. Данные о здоровье остаются вашими: результаты лабораторий разбираются автоматически, статусы отдельных патогенов **никогда** никому не показываются, а подбор пар основан только на анонимных вердиктах совместимости (Safe / Compatible / Caution / Risk). Чат работает peer-to-peer через libp2p и Nostr, с HTTP-фолбэком для удобства; приложение включает лёгкий публичный фасад «Safety Mode», а также автономный режим Companion Mode для оценки результатов STD-тестов.

> **Статус: ранняя альфа.** EVOLVE находится в активной разработке и не является готовым продуктом.
> Смарт-контракты задеплоены **только в тестовой сети Ethereum Sepolia**.
> **Нет деплоя в майннет, нет DEX, нет ликвидности и нет публичной продажи токенов** — и ничего из этого не обещается.
> Функции могут меняться или ломаться в любой момент. Ничто здесь не является финансовым советом или инвестиционным предложением.

## Что и зачем

Традиционные платформы знакомств просят отдать номер телефона, почту, фото и интимные детали здоровья в центральную базу данных. EVOLVE исходит из противоположной посылки: приватность по умолчанию, самохранение и отсутствие центральной точки отказа. Ключевые ценности:

- **Приватность по умолчанию** — данные о здоровье никогда не раскрываются; только анонимные вердикты.
- **Устойчивость к блокировкам** — обмен сообщениями в первую очередь P2P, децентрализованное хранение (IPFS / Arweave), мульти-сетевой дизайн, никаких захардкоженных доменов.
- **Самохранимая идентичность** — ваш кошелёк и есть ваш логин; восстановление на основе DNA вместо почты/телефона.
- **Нет KYC-барьера** — для использования платформы не нужны удостоверение личности, телефон или почта.

Полное обоснование читайте в [docs/WHAT-AND-WHY.md](docs/WHAT-AND-WHY.md) (на английском).

## Ключевые возможности

### Идентичность и приватность

- **Вход через кошелёк SIWE** (MetaMask и другие EVM-кошельки) — устойчивый к цензуре запасной выход.
- **Восстановление аккаунта через DNA** — результат вашего DNA-теста хешируется (SHA-256, фиксируется ончейн как `bytes32`) и может восстановить доступ без телефона и почты.
- **Абстракция аккаунта (ERC-4337)** — смарт-аккаунты и пеймастер для онбординга без газа; SIWE всегда остаётся доступным.

### Анонимная совместимость по здоровью

- Загрузка результатов STD-тестов в виде текста или PDF (извлечение текстового слоя с OCR-фолбэком для отсканированных страниц).
- Парсер распознаёт 8 патогенов: ВИЧ-1/2, сифилис, хламидиоз, гонорея, HSV-1, HSV-2, гепатит B, гепатит C (форматы отчётов на английском, украинском и русском).
- **Статусы отдельных патогенов никогда не показываются другим пользователям.** В профилях отображается только анонимный вердикт: **Safe / Compatible / Caution / Risk**.
- Ончейн-записи верификации DNA (`DNAVerification.sol`) обеспечивают процессы восстановления и подтверждения.

### Профили, поиск и общение

- Фильтры поиска: «что вы ищете» (знакомства / зачатие / полиандрическое зачатие / STD-тестирование), «кого вы ищете» (мужчины, женщины, пары), каскадные выборы страна → город, «может приехать в вашу страну» со списками по странам, цвет кожи, предпочтения по тестированию, только STD-совместимые.
- Мастер онбординга: возраст (можно скрыть), языки, био, фото.
- **Приватность фото**: фото по умолчанию размыты; владелец выдаёт доступ на 15 секунд или постоянно — по своей инициативе или по запросу. Просмотр бесплатный.
- **P2P-чат** через libp2p (gossipsub) + Nostr, с HTTP API-фолбэком.

### Режимы зачатия

- **Режим 2 — Pregnancy Bond**: женщина создаёт бонд, мужчина стейкает EVOLVE (≥ 100 в текущей тестовой сборке), оба подтверждают; после подтверждённой беременности и отцовства стейк переходит женщине.
- **Режим 3 — Cryptic Choice**: женщина открывает 48-часовую сессию, мужчины присоединяются со стейком; она выбирает отца — его стейк возвращается, остальные делят: 90% ей / 10% выбранному отцу.

### Лаборатории и верификация

- **Процесс для лабораторий-партнёров**: лаборатории регистрируются как партнёры, подтверждают пациентов по QR-коду и совпадению лица и прикрепляют STD-отчёты (PDF/текст с OCR-извлечением).
- **Companion Mode**: автономный процесс оценки результатов STD-тестов без регистрации на платформе знакомств.
- **Safety Mode** (`VITE_PRODUCT_MODE=safety`): ограниченный публичный фасад (статус STD, публичные ссылки на профили, проверки совместимости), который продолжает работать, даже если функции знакомств/зачатия ограничены в какой-либо юрисдикции или магазине приложений.

### Токен EVOLVE (только тестовая сеть)

- ERC-20, максимальная эмиссия 8 000 000 000 EVOLVE, административные действия защищены 48-часовым TimelockController.
- **Экономика эмодзи-подарков**: подарок стоит 1 EVOLVE, который распределяется пропорционально между существующими владельцами подарков — бессрочная модель дохода для держателей; подарки передаваемы.
- **EvolveFund**: мужской стейкинг (минимум 15 EVOLVE, блокировка на 30 дней), учитываемый в весе управления; женщины используют баланс кошелька.
- **Награды за верификацию**: 1 EVOLVE верифицированному пользователю и 1 EVOLVE подтверждающей лаборатории при STD/DNA-верификации (плюс ограниченный по частоте тестовый faucet).
- Вес голоса в управлении объединяет рекурсивную репутацию (8 голосов, глубина 3), долю детей/отцовства и застейканные или удерживаемые EVOLVE.
- Интеграция **LayerZero OFT** для будущих мультичейн-переводов EVOLVE (зависимости на месте; помимо Sepolia пока ничего не задеплоено).

### Платформа

- Веб-приложение (устанавливается как PWA) и мобильное приложение на Expo/React Native.
- Интерфейс переведён на **34 языка**.
- Готовность к мульти-сетям: 18 конфигураций EVM-сетей (Arbitrum и Avalanche — планируемые основные L2 — **пока не задеплоены**).

## Архитектура и технологический стек

Монорепозиторий под управлением npm workspaces + Turborepo:

```
apps/
  web/          # Vite + React + TypeScript (main web app, i18next, Prisma)
  mobile/       # Expo + React Native
packages/
  config/       # Feature flags & dynamic remote configuration
  contracts/    # Solidity 0.8.24, Hardhat, Ignition, OpenZeppelin, LayerZero
  core/         # Shared types, utilities, middleware, web3
  matching/     # Matching algorithms, filters, ranking
  p2p/          # libp2p (gossipsub) + Nostr networking
  storage/      # IPFS, Arweave, Lit Protocol
docs/           # Architecture, tokenomics, roadmap, FAQ
```

Ключевые смарт-контракты: `EVOLVE.sol` (ERC-20), `ProfileNFT.sol` (ERC-721), `TrustScore.sol`, `Voting.sol`, `Evolve2Earn.sol` (эмодзи-подарки + награды), `Governance.sol`, `BondManager.sol` (режимы 2 и 3), `EvolveFund.sol`, `VerificationRegistry.sol`, `DNAVerification.sol`, ERC-4337 `SmartAccountFactory` + `Paymaster` и `TimelockController` от OpenZeppelin.

Подробнее: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) · [docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md) · [docs/TOKENOMICS.md](docs/TOKENOMICS.md) (на английском).

## Дорожная карта

В процессе: производственная готовность веб-приложения. Запланировано: ончейн-реестр лабораторий и сертификация тестов, реальный адаптер почтового провайдера для приёма лабораторных отчётов, ончейн-подтверждённые аттестации в профилях, обновление вестинга токенов для долей основателей/разработчиков, обеспечение ликвидности на DEX (сейчас заблокировано — требуются майннет-деплои токена). Мульти-сетевое расширение (Arbitrum, Avalanche и другие EVM-цепочки) последует после укрепления тестовой сети.

Полный список: [docs/ROADMAP.md](docs/ROADMAP.md) (на английском).

## Начало работы (разработчикам)

Требования: **Node.js 20+** и npm 10.x.

```bash
# Clone and install all workspaces
git clone https://github.com/Lilit-Moonlit/Evolve.git
cd Evolve
npm install

# Web app (Vite dev server on http://localhost:3000)
cd apps/web
npm run dev
npm test                # vitest suite

# Smart contracts
cd packages/contracts
npm run compile         # hardhat compile
npm test                # hardhat test suite
npm run deploy:local    # deploy all contracts to an in-process Hardhat network
```
