# EVOLVE

**Знакомства, зачатие и проверенное здоровье — конфиденциальность по умолчанию, доверие там, где это действительно важно.**

EVOLVE — платформа с открытым кодом, созданная для людей, которые устали отдавать свой номер телефона, своё лицо и самые интимные данные о здоровье в чужую базу. Вы входите со своим крипто-кошельком — без телефона, без электронной почты, без KYC — и можете вернуть аккаунт через обязательство DNA в блокчейне. Данные о здоровье остаются вашими: результаты анализов разбираются автоматически, статус отдельных патогенов **никогда** никому не показывается, а подбор пар основан только на анонимных вердиктах совместимости (Safe / Compatible / Caution / Risk). Чат работает peer-to-peer через libp2p и Nostr, с HTTP-фолбэком для удобства.

> **Статус — платформа работает уже сегодня; далее mainnet и DEX.**
> Знакомства, зачатие, верификация здоровья, лабораторный поток, P2P-чат, токен EVOLVE и управление — всё это работает. Впереди: **деплой в mainnet и ликвидность на DEX**, а также **запланированная публичная продажа** (см. [Токен EVOLVE](#токен-evolve-только-тестнет)).
> Смарт-контракты задеплоены **только в тестовой сети Ethereum Sepolia**. Ничто здесь не является финансовым советом или инвестиционным предложением.

> **EVOLVE полезен вам? Поддержите разработку — каждое пожертвование идёт на код, партнёрства с лабораториями, хостинг и перевод → [DONATE.md](DONATE.md).**

## Что и почему

Обычные приложения для знакомств просят обменять ваш номер телефона, электронную почту, фото и интимные детали здоровья на центральную базу данных — а затем вечно доверять этой базе. EVOLVE исходит из противоположной посылки: **приватность по умолчанию, самосохранность (self-custody) и отсутствие единой точки отказа**.

- **Приватность по умолчанию** — данные о здоровье никогда не раскрываются; только анонимные вердикты.
- **Устойчивость к блокировкам** — в первую очередь P2P-мессенджинг, децентрализованное хранилище, мульти-сетевой дизайн, без захардкоженных доменов.
- **Самохранная идентичность** — ваш кошелёк и есть ваш логин; восстановление через DNA вместо электронной почты или телефона.
- **Без KYC-барьера** — для пользования платформой не нужны удостоверение личности, телефон или электронная почта.

Полное обоснование — в [docs/WHAT-AND-WHY.md](docs/WHAT-AND-WHY.md).

## Здоровье, которому действительно можно верить

- Загрузите результат STD-анализа как текст или PDF (извлечение текстового слоя, с OCR-фолбэком для сканов).
- Парсер знает 8 патогенов: HIV-1/2, сифилис, хламидиоз, гонорея, HSV-1, HSV-2, гепатит B, гепатит C — в форматах отчётов на английском, украинском и русском.
- **Статус отдельного патогена никогда не показывается другим пользователям.** Профили показывают только анонимный вердикт: **Safe / Compatible / Caution / Risk**.
- Записи DNA в блокчейне (`DNAVerification.sol`) обеспечивают восстановление и верификацию.

### Партнёрские лаборатории — факты, а не обещания

Придите в партнёрскую лабораторию и покажите свой QR-код. Лаборатория сканирует его, подтверждает вашу личность **распознаванием лица** (чтобы никто другой не мог забрать ваш результат) и прикладывает STD-отчёт — PDF, скан или текст, даже с плохим OCR. Результат подписан настоящей лабораторией, а не вами, поэтому другие видят **проверенный факт** вместо вашего слова. И каждое подтверждённое верифицирование выплачивает **1 EVOLVE пациенту и 1 EVOLVE лаборатории** — у обеих сторон есть причина быть честными. Отдельные патогены по-прежнему никому не показываются.

## Поиск человека

- Фильтры поиска: «Что вы ищете» (знакомства / зачатие / полиандрическое зачатие / сдача STD-анализов), «Кого вы ищете» (мужчины, женщины, пары), каскадные выборы страна → город, «может приехать в вашу страну» со списками по странам, цвет кожи, предпочтение по тестированию, только STD-совместимые.
- Мастер онбординга: возраст (можно скрыть), языки, био, фото.
- **P2P-чат** через libp2p (gossipsub) + Nostr, с фолбэком на HTTP API.

## Зачатие

Два пути планирования ребёнка, и оба строятся на одной идее: настоящее намерение подтверждается реальной ставкой в EVOLVE — никогда обещаниями. Обязательство мужчины живёт в его депозите EvolveFund (от 15 EVOLVE, заморожен минимум на 30 дней), а женщина может установить свой минимальный депозит для мужчин, которые к ней обращаются.

**Зачатие.** Ведёт женщина: она приглашает конкретного мужчину и закрепляет его в бонде. Ему нужен активный депозит EvolveFund; когда оба подтверждают, он блокируется и начинается обратный отсчёт. Беременность фиксируется между 14 и 30 днями после подтверждения, а анализы STD и DNA пара сдаёт на самой встрече — важны свежие результаты STD, ДНК не стареет. Когда отцовство подтверждено, депозит мужчины переходит женщине; если не подтверждено — депозит просто возвращается ему. Ничто не переходит из рук в руки, пока факты не установлены.

**Полиандрическое зачатие.** Выбор принадлежит ей и остаётся приватным. Она открывает сессию на 48 часов — без собственного депозита (она может добавить его только ради репутации, если захочет). Мужчины с активным депозитом могут присоединиться — до 50 — и подтвердить участие, что блокирует их ставку. Через четырнадцать дней после закрытия сессии выбирается отец. Он получает свой депозит обратно плюс награду из пула: удвоенный депозит и 1 EVOLVE за каждого другого участника. Невыбранные мужчины теряют свою ставку — 90% женщине, 10% выбранному отцу. Она ничем не рискует и может только выиграть; мужчины ставят свои средства за право быть выбранными.

## Токен EVOLVE (только тестнет)

- ERC-20, максимальное предложение **8,000,000,000 EVOLVE**. Административные действия ограничены 48-часовым `TimelockController`.
- **Запланированное распределение предложения** — спроектировано так, чтобы почти весь запас работал на пользователей, а не на инсайдеров:

| Назначение                                                  |        EVOLVE |
| ----------------------------------------------------------- | ------------: |
| Основатели и команда (зарплата / вознаграждение)            |    25,000,000 |
| Резерв DEX (будущее)                                        |     4,000,000 |
| Публичная продажа (запланирована)                           |     5,000,000 |
| Резерв вознаграждений — лаборатории, пациенты, матери, отцы | 7,966,000,000 |

- **Запланированная публичная продажа** — 5,000,000 EVOLVE продаются приложением по **$0.8 за токен**, оплата любым токеном, который поддерживает приложение; выручка идёт на разработку. _(Запланировано — пока не запущено.)_
- **Бездоверительная эмиссия (запланирована)** — резерв вознаграждений ~7,966,000,000 планируется запереть в неопустошаемом `RewardVault`: выпуск только постепенно через вознаграждения лабораториям, пациентам, матерям и отцам, а изменение правил требует голосования в системе управления. Даже основатель не сможет вывести его. Дизайн: [docs/REWARD-VAULT-PLAN.md](docs/REWARD-VAULT-PLAN.md).
- **Экономика эмодзи-подарков** — подарок стоит 1 EVOLVE и делится пропорционально между существующими владельцами подарков; модель бессрочного дохода, подарки передаваемы.
- **EvolveFund** — мужской стейкинг (минимум 15 EVOLVE, блокировка на 30 дней), учитываемый в весе голоса; женщины используют баланс кошелька.
- **Вознаграждения за верификацию** — 1 EVOLVE верифицированному пользователю и 1 EVOLVE подтверждающей лаборатории за каждую STD/DNA-верификацию (плюс faucet с ограничением частоты).
- **Управление** — вес голоса объединяет рекурсивную репутацию (8 голосов, глубина 3), долю детей/отцовства и застейканные или удерживаемые EVOLVE.
- Интеграция **LayerZero OFT** для будущих мультичейн-переводов EVOLVE (зависимости на месте; кроме Sepolia пока ничего не задеплоено).

## Архитектура и технологический стек

Монорепозиторий под управлением npm workspaces + Turborepo:

```
apps/
  web/          # Vite + React + TypeScript (main web app, i18next, Prisma)
  mobile/       # Expo + React Native
packages/
  config/       # Feature flags & dynamic remote configuration
  contracts/    # Solidity 0.8.24, Hardhat, Ignition, OpenZeppelin, LayerZero
  core/         # Shared types, utilities, middleware, web3
  matching/     # Matching algorithms, filters, ranking
  p2p/          # libp2p (gossipsub) + Nostr networking
  storage/      # IPFS, Arweave, Lit Protocol
docs/           # Architecture, tokenomics, roadmap, FAQ
```

Ключевые смарт-контракты: `EVOLVE.sol` (ERC-20), `ProfileNFT.sol` (ERC-721), `TrustScore.sol`, `Voting.sol`, `Evolve2Earn.sol` (эмодзи-подарки + вознаграждения), `Governance.sol`, `BondManager.sol` (зачатие и полиандрическое зачатие), `EvolveFund.sol`, `VerificationRegistry.sol`, `DNAVerification.sol`, ERC-4337 `SmartAccountFactory` + `Paymaster` и `TimelockController` от OpenZeppelin.

Подробности: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) · [docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md) · [docs/TOKENOMICS.md](docs/TOKENOMICS.md)

## Начало работы (разработчикам)

Требования: **Node.js 20+** и npm 10.x.

```bash
# Clone and install all workspaces
git clone https://github.com/Lilit-Moonlit/Evolve.git
cd Evolve
npm install

# Web app (Vite dev server on http://localhost:3000)
cd apps/web
npm run dev
npm test                # vitest suite

# Smart contracts
cd packages/contracts
npm run compile         # hardhat compile
npm test                # hardhat test suite
npm run deploy:local    # deploy all contracts to an in-process Hardhat network
```
