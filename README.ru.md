# EVOLVE

**Знакомства, зачатие и проверенное здоровье — приватность по умолчанию, доверие там, где оно важно.**

EVOLVE — это open-source децентрализованная платформа для людей, которым надоело отдавать свой номер телефона, своё лицо и самые интимные данные о здоровье в чужую базу. Вы входите собственным крипто-кошельком — без телефона, без email, без KYC — а доступ к аккаунту можно вернуть через ончейн-обязательство ДНК. Данные о здоровье остаются вашими: результаты анализов разбираются автоматически, индивидуальные статусы патогенов **никогда** никому не показываются, а матчинг опирается только на анонимные вердикты совместимости (Safe / Compatible / Caution / Risk). Чат работает однорангово через libp2p и Nostr, с HTTP-фолбэком для удобства. Подарки и переводы движутся к полной конфиденциальности: приватные подарки уже работают, а впереди — защищённый кошелёк Railgun и прототип на zero-knowledge от Aztec (см. [Приватность и конфиденциальные транзакции](#приватность--конфиденциальные-транзакции)).

> **Статус — демо-режим, активная разработка.**
> Знакомства, зачатие, верификация здоровья, лабораторный поток, P2P-чат, токен EVOLVE и управление уже реализованы и работают в **локальном демо** — приложение **ещё не развёрнуто публично**. Впереди: **деплой в mainnet и ликвидность на DEX**, а также **запланированная публичная продажа** (см. [Токен EVOLVE](#токен-evolve-только-тестнет)).
> Смарт-контракты развёрнуты **только в тестовой сети Ethereum Sepolia**. Ничто здесь не является финансовым советом или инвестиционным предложением.

> **EVOLVE вам полезен? Поддержите разработку — каждый донат идёт на код, партнёрства с лабораториями, хостинг и переводы → [DONATE.md](DONATE.md).**

## Бояться нечего

EVOLVE строился вокруг вопросов, которые люди на самом деле задают, прежде чем довериться такой платформе.

| ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| «Мои фото где-то окажутся.»               | Фото по умолчанию размыто. Владелец предоставляет просмотр на **15 секунд** или **постоянный** — по запросу или проактивно. Просмотр бесплатный.                                                                |
| «Придётся отдать паспорт или телефон.»    | Вход через кошелёк (SIWE). Без телефона, без email, без KYC. Восстановление — через ончейн-обязательство ДНК.                                                                                                   |
| «Он или она лгут о здоровье.»             | Результаты **верифицирует лаборатория** (QR + распознавание лица), а анализы сдаются **на самой встрече** — свежесть ИППП важна, ДНК не стареет.                                                                |

## Что и почему

Обычные дейтинг-приложения просят обменять ваш номер телефона, email, фото и интимные детали здоровья на централизованную базу — а потом доверять этой базе вечно. EVOLVE начинает с противоположного принципа: **приватность по умолчанию, самосохранение (self-custody) и отсутствие единой точки отказа**.

- **Приватность по умолчанию** — данные о здоровье не раскрываются; только анонимные вердикты.
- **Устойчивость к банам** — P2P-сообщения в первую очередь, децентрализованное хранилище, мультисетевая архитектура, без хардкоженных доменов.
- **Самосохранённая идентичность** — ваш кошелёк — ваш логин; восстановление через ДНК вместо email или телефона.
- **Без KYC** — для использования платформой не нужны документы, телефон или email.

Полное изложение: [docs/WHAT-AND-WHY.md](docs/WHAT-AND-WHY.md).

## Здоровье, которому можно доверять

- Загрузка результатов ИППП-тестов как текст или PDF (извлечение текстового слоя, с OCR-фолбэком для сканов).
- Парсер распознаёт 8 патогенов: ВИЧ-1/2, сифилис, хламидиоз, гонорея, ВПГ-1, ВПГ-2, гепатит B, гепатит C — в форматах отчётов на английском, украинском и русском.
- **Индивидуальный статус патогенов никогда не показывается другим пользователям.** В профилях только анонимный вердикт: **Safe / Compatible / Caution / Risk**.
- Ончейн-записи ДНК (`DNAVerification.sol`) обеспечивают восстановление и верификацию.

### Лаборатории-партнёры — доказательство, а не обещание

Приходите в лабораторию-партнёр и покажите свой QR-код. Лаборатория сканирует его, подтверждает вашу личность **распознаванием лица** (чтобы результат не получил кто-то другой) и прикрепляет отчёт об ИППП — PDF, скан или текст, даже с плохим OCR. Результат подписывает реальная лаборатория, а не вы сами, поэтому другие видят **верифицированный факт**, а не ваши слова. И за каждую подтверждённую верификацию **и пациент, и лаборатория получают по 1 EVOLVE** — мотивация не лгать есть у обеих сторон. Индивидуальные патогены при этом всё равно никому не показываются.

## Поиск человека

- Фильтры поиска: «Что вы ищете» (знакомства / зачатие / полиандрическое зачатие / сдача ИППП-тестов), «Кого вы ищете» (мужчины, женщины, пары), каскадные селекты страна → город, «может приехать в мою страну» со списками стран, цвет кожи, предпочтение по тестированию, только ИППП-совместимые.
- Мастер онбординга: возраст (можно скрыть), языки, био, фото.
- **P2P-чат** через libp2p (gossipsub) + Nostr, с фолбэком на HTTP API.

## Зачатие

Два способа спланировать ребёнка, и оба держатся на одном: настоящий намерение подтверждается реальной долей EVOLVE — а не обещаниями. Обязательство мужчины — это его депозит в EvolveFund (от 15 EVOLVE, заблокированный минимум на 30 дней), а женщина может сама установить минимальный депозит для тех, кто до неё доходит.

**Зачатие.** Инициатива — за женщиной: она приглашает конкретного мужчину и называет его в бонде. У него должен быть активный депозит в EvolveFund; когда оба подтверждают, депозит блокируется и начинается отсчёт. О беременности сообщают на 14–30-й день после подтверждения, а анализы на ИППП и ДНК сдаются на самой встрече — свежесть результатов ИППП важна, ДНК не стареет. Когда отцовство подтверждено, депозит мужчины переходит женщине; если нет — депозит просто возвращается ему. Ничто не переходит из рук в руки, пока факты не установлены.

**Полиандрическое зачатие.** Здесь выбор — за ней, и остаётся приватным. Она открывает сессию на 48 часов — без собственного депозита (по желанию может внести вклад только для репутации). Присоединяются мужчины с активным депозитом: до 50, каждый подтверждает участие и замораживает свою долю. Через 14 дней после закрытия сессии выбирают отца. Он получает обратно свой депозит и награду из пула: двойной депозит плюс 1 EVOLVE за каждого другого участника. Мужчины, которых не выбрали, теряют свою долю: 90% переходит женщине, 10% — выбранному отцу. Она ничем не рискует — только выигрывает; мужчины же ставят свою долю за право быть выбранными.

## Приватность и конфиденциальные транзакции

Приватность — по умолчанию, и EVOLVE строит дорожную карту к полностью конфиденциальным ончейн-переводам.

- **Приватные подарки** — отправьте розу 🌹 или кактус 🌵 (1 EVOLVE) и выберите, кто будет видеть, что это вы: _публично_, _анонимно для всех, кроме получателя_ или _полностью анонимно_. В анонимных режимах подарок перемещается как одноразовый ваучер, который получатель погашает своим кошельком, поэтому отправитель никогда не появляется на блокчейне. (Анонимность отправителя сегодня «бытового» уровня: транзакцию финансирования можно сопоставить по времени и сумме.)
- **Защищённый кошелёк Railgun** — приватный кошелёк за фича-флагом (`VITE_RAILGUN_ENABLED`, выключен по умолчанию), который скрывает суммы и адреса через живой zero-knowledge пул Railgun. Это путь к настоящей анонимности отправителя.
- **Прототип Aztec** — та же логика приватных переводов и приватных бондов, выраженная как zero-knowledge схемы Noir и удерживаемая за явным барьером, пока Aztec не станет готовым к продакшену. См. [docs/AZTEC-PROTOTYPE.md](docs/AZTEC-PROTOTYPE.md).
- **Модель двух кошельков** — публичный кошелёк-доля участвует в управлении; приватный защищённый кошелёк намеренно **исключён** из веса голоса, поэтому приватность и сила голоса держатся раздельно.

Детали: [docs/RAILGUN-INTEGRATION.md](docs/RAILGUN-INTEGRATION.md) · [docs/SHIELDED-STAKES-DESIGN.md](docs/SHIELDED-STAKES-DESIGN.md) · [docs/AZTEC-PROTOTYPE.md](docs/AZTEC-PROTOTYPE.md).

## Токен EVOLVE (только тестнет)

- ERC-20, максимальная эмиссия **8 000 000 000 EVOLVE**. Админ-действия под 48-часовым `TimelockController`.
- **Запланированное распределение эмиссии** — почти вся эмиссия должна работать на пользователей, а не на инсайдеров:

| Назначение                                                  |        EVOLVE |
| ----------------------------------------------------------- | ------------: |
| Основатели и команда (зарплата / вознаграждение)            |    25 000 000 |
| Резерв на DEX (будущее)                                     |     4 000 000 |
| Публичная продажа (запланировано)                           |     5 000 000 |
| Резерв вознаграждений — лаборатории, пациенты, матери, отцы | 7 966 000 000 |

- **Запланированная публичная продажа** — 5 000 000 EVOLVE продаются приложением по **$0.8 за токен**, оплата любым токеном, который поддерживает приложение; выручка идёт на разработку. _(Запланировано — пока не запущено.)_
- **Trustless-эмиссия (запланировано)** — резерв вознаграждений ~7 966 000 000 планируется запереть в неопустошаемом `RewardVault`: он высвобождается только постепенно через вознаграждения лабораториям, пациентам, матерям и отцам, а изменение правил требует голосования. Вывести его не сможет даже основатель. Дизайн: [docs/REWARD-VAULT-PLAN.md](docs/REWARD-VAULT-PLAN.md).
- **Экономика эмодзи-подарков** — подарок стоит 1 EVOLVE, который распределяется пропорционально между владельцами существующих подарков; бессрочная модель дохода, подарки можно передавать.
- **EvolveFund** — мужской стейкинг (мин 15 EVOLVE, блокировка 30 дней), который учитывается в весе управления; женщины используют баланс кошелька.
- **Награды за верификацию** — 1 EVOLVE верифицированному пользователю и 1 EVOLVE подтвердившей лаборатории за верификацию ИППП/ДНК (плюс лимитированный faucet).
- **Управление** — вес голоса сочетает рекурсивную репутацию (8 голосов, глубина 3), долю детей/отцовства и застейканные или просто удерживаемые EVOLVE.
- Интеграция **LayerZero OFT** для будущих мультичейн-переводов EVOLVE (зависимости подключены; пока нигде, кроме Sepolia, не развёрнуто).

## Архитектура и технологический стек

Монорепозиторий на npm workspaces + Turborepo:

```
apps/
  web/          # Vite + React + TypeScript (основное веб-приложение, i18next, Prisma)
  mobile/       # Expo + React Native
packages/
  config/       # Фича-флаги и динамическая удалённая конфигурация
  contracts/    # Solidity 0.8.24, Hardhat, Ignition, OpenZeppelin, LayerZero
  core/         # Общие типы, утилиты, middleware, web3
  matching/     # Алгоритмы матчинга, фильтры, ранжирование
  p2p/          # Сетевое взаимодействие libp2p (gossipsub) + Nostr
  storage/      # IPFS, Arweave, Lit Protocol
docs/           # Архитектура, токеномика, дорожная карта, FAQ
```

Ключевые смарт-контракты: `EVOLVE.sol` (ERC-20), `ProfileNFT.sol` (ERC-721), `TrustScore.sol`, `Voting.sol`, `Evolve2Earn.sol` (эмодзи-подарки + награды), `Governance.sol`, `BondManager.sol` (зачатие и полиандрическое зачатие), `EvolveFund.sol`, `VerificationRegistry.sol`, `DNAVerification.sol`, ERC-4337 `SmartAccountFactory` + `Paymaster`, а также `TimelockController` от OpenZeppelin.

Детали: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) · [docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md) · [docs/TOKENOMICS.md](docs/TOKENOMICS.md)

## Начало работы (разработчикам)

Требования: **Node.js 20+** и npm 10.x.

```bash
# Клонировать и установить все workspace
git clone https://github.com/Lilit-Moonlit/Evolve.git
cd Evolve
npm install

# Веб-приложение (Vite dev-сервер на http://localhost:3000)
cd apps/web
npm run dev
npm test                # набор тестов vitest

# Смарт-контракты
cd packages/contracts
npm run compile         # hardhat compile
npm test                # набор тестов hardhat
npm run deploy:local    # развернуть все контракты в локальной сети Hardhat
```
