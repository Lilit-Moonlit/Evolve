Here are the instructions to obtain a WalletConnect Project ID:

1. Go to cloud.walletconnect.com
2. Create an account or log in.
3. In your dashboard, create a new project.
4. Your Project ID will be displayed on the project settings page. Copy this ID and use it in your application.

## Supported Networks

- **Arbitrum**: Our primary L2 network, offering inheriting Ethereum security, ultra-low fees, massive liquidity, and a robust ecosystem.
- **Avalanche**: Added to expand user capabilities, providing sub-second transaction finality, extremely low gas costs, a large user base, and exceptional stability.
