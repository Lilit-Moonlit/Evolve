# EVOLVE

**Знайомства, зачаття та перевірене здоров'я — приватність за замовчуванням, довіра там, де вона важлива.**

EVOLVE — це open-source децентралізована платформа для людей, які втомилися віддавати свій номер телефону, обличчя та найінтимніші дані про здоров'я в чужу базу. Ви входите власним крипто-гаманцем — без телефону, без email, без KYC — а доступ до акаунта можете повернути через ончейн-зобов'язання ДНК. Дані про здоров'я залишаються вашими: результати аналізів парсяться автоматично, індивідуальні статуси патогенів **ніколи** нікому не показуються, а матчинг спирається лише на анонімні вердикти сумісності (Safe / Compatible / Caution / Risk). Чат працює однорангово через libp2p і Nostr, з HTTP-фолбеком для зручності.

> **Стан — платформа вже працює; mainnet і DEX — наступні.**
> Знайомства, зачаття, перевірка здоров'я, потік лабораторій, P2P-чат, токен EVOLVE та управління вже працюють. Попереду: **розгортання в mainnet і ліквідність на DEX**, а також **запланований публічний продаж** (див. [Токен EVOLVE](#токен-evolve-лише-тестова-мережа)).
> Смарт-контракти розгорнуті **лише в тестовій мережі Ethereum Sepolia**. Ніщо тут не є фінансовою порадою чи інвестиційною пропозицією.

> **EVOLVE вам корисний? Підтримайте розробку — кожен донат іде на код, партнерства з лабораторіями, хостинг і переклади → [DONATE.md](DONATE.md).**

## Що і чому

Звичайні дейтинг-додатки просять обміняти ваш номер телефону, email, фото та інтимні деталі здоров'я на централізовану базу — а потім довіряти цій базі вічно. EVOLVE починає з протилежної засади: **приватність за замовчуванням, самозбереження (self-custody) і відсутність єдиної точки відмови**.

- **Приватність за замовчуванням** — дані про здоров'я не розкриваються; лише анонімні вердикти.
- **Стійкість до банів** — P2P-повідомлення насамперед, децентралізоване сховище, мультимережева архітектура, без хардкодених доменів.
- **Самозбережена ідентичність** — ваш гаманець є вашим логіном; відновлення через ДНК замість email чи телефону.
- **Без KYC** — для користування платформою не потрібні документи, телефон чи email.

Повний виклад: [docs/WHAT-AND-WHY.md](docs/WHAT-AND-WHY.md) (англійською).

## Здоров'я, якому можна довіряти

- Завантаження результатів ІПСШ-тестів як текст або PDF (витяг текстового шару, з OCR-фолбеком для сканів).
- Парсер розпізнає 8 патогенів: ВІЛ-1/2, сифіліс, хламідіоз, гонорея, ВПГ-1, ВПГ-2, гепатит B, гепатит C — у форматах звітів англійською, українською та російською.
- **Індивідуальний статус патогенів ніколи не показується іншим користувачам.** У профілях лише анонімний вердикт: **Safe / Compatible / Caution / Risk**.
- Ончейн-записи ДНК (`DNAVerification.sol`) забезпечують відновлення та верифікацію.

### Лабораторії-партнери — доказ, а не обіцянка

Приходьте в лабораторію-партнер і покажіть свій QR-код. Лабораторія сканує його, підтверджує вашу особу **розпізнаванням обличчя** (щоб результат не отримав хтось інший) і долучає звіт про ІПСШ — PDF, скан або текст, навіть із поганим OCR. Результат підписує реальна лабораторія, а не ви самі, тож інші бачать **верифікований факт**, а не ваші слова. І за кожну підтверджену верифікацію **і пацієнт, і лабораторія отримують по 1 EVOLVE** — мотивація не брехати є в обох сторін. Індивідуальні патогени при цьому все одно нікому не показуються.

## Пошук людини

- Фільтри пошуку: «Що ви шукаєте» (знайомства / зачаття / поліандрічне зачаття / здача ІПСШ-тестів), «Кого ви шукаєте» (чоловіки, жінки, пари), каскадні селекти країна → місто, «може прибути до моєї країни» зі списками країн, колір шкіри, перевага щодо тестування, лише ІПСШ-сумісні.
- Майстер онбордингу: вік (можна приховати), мови, біо, фото.
- **P2P-чат** через libp2p (gossipsub) + Nostr, з фолбеком на HTTP API.

## Зачаття

Два способи спланувати дитину, і обидва тримаються на одному: справжній намір підтверджується реальною часткою EVOLVE — а не обіцянками. Зобов'язання чоловіка — це його депозит в EvolveFund (від 15 EVOLVE, заблокований щонайменше на 30 днів), а жінка може сама встановити мінімальний депозит для тих, хто до неї доходить.

**Зачаття.** Ініціатива — за жінкою: вона запрошує конкретного чоловіка й називає його в бонді. Він має мати активний депозит в EvolveFund; коли обидва підтверджують, депозит блокується і починається відлік. Про вагітність повідомляють на 14–30-й день після підтвердження, а аналізи на ІПСШ та ДНК здаються на самій зустрічі — свіжість результатів ІПСШ важлива, ДНК не старіє. Коли батьківство підтверджено, депозит чоловіка переходить жінці; якщо ні — депозит просто повертається йому. Ніщо не переходить з рук у руки, доки факти не встановлені.

**Поліандрічне зачаття.** Тут вибір — за нею, і лишається приватним. Вона відкриває сесію, що триває 48 годин — без власного депозиту (за бажанням вона може зробити внесок лише для репутації). Приєднуються чоловіки з активним депозитом: до 50, кожен підтверджує участь і заморожує свою частку. Через 14 днів після закриття сесії обирають батька. Він отримує назад свій депозит і винагороду з пулу: подвійний депозит плюс 1 EVOLVE за кожного іншого учасника. Чоловіки, яких не обрали, втрачають свою частку: 90% переходить жінці, 10% — обраному батькові. Вона нічим не ризикує — лише виграє; чоловіки ж ставлять свою частку за право бути обраними.

## Токен EVOLVE (лише тестова мережа)

- ERC-20, максимальна емісія **8 000 000 000 EVOLVE**. Адмін-дії під 48-годинним `TimelockController`.
- **Запланований розподіл емісії** — майже вся емісія має працювати на користувачів, а не на інсайдерів:

| Призначення                                              |        EVOLVE |
| -------------------------------------------------------- | ------------: |
| Засновники та команда (зарплата / винагорода) | 25 000 000 |
| Резерв на DEX (майбутнє)                                 |     4 000 000 |
| Публічний продаж (заплановано)                           |     5 000 000 |
| Резерв винагород — лабораторії, пацієнти, матері, батьки | 7 966 000 000 |

- **Запланований публічний продаж** — 5 000 000 EVOLVE продаються додатком по **$0.8 за кожен**, оплата будь-яким токеном, який підтримує додаток; кошти йдуть на розвиток. _(Заплановано — ще не запущено.)_
- **Trustless-емісія (заплановано)** — резерв винагород ~7 966 000 000 планується замкнути в невисаджуваному `RewardVault`: він вивільняється лише поступово через винагороди лабораторіям, пацієнтам, матерям і батькам, а зміна правил потребує голосування. Зняти його не зможе навіть засновник. Дизайн: [docs/REWARD-VAULT-PLAN.md](docs/REWARD-VAULT-PLAN.md).
- **Економіка емодзі-подарунків** — подарунок коштує 1 EVOLVE, який розподіляється пропорційно між власниками наявних подарунків; безстрокова модель доходу, подарунки можна передавати.
- **EvolveFund** — чоловічий стейкінг (мін 15 EVOLVE, блокування 30 днів), який враховується у вагі управління; жінки використовують баланс гаманця.
- **Нагороди за верифікацію** — 1 EVOLVE верифікованому користувачу та 1 EVOLVE лабораторії, що підтвердила, за верифікацію ІПСШ/ДНК (плюс лімітований faucet).
- **Управління** — вага голосу поєднує рекурсивну репутацію (8 голосів, глибина 3), частку дітей/батьківства та застейкані або просто тримані EVOLVE.
- Інтеграція **LayerZero OFT** для майбутніх мультичейн-переводів EVOLVE (залежності підключені; поки що ніде, крім Sepolia, не розгорнуто).

## Архітектура і технологічний стек

Монорепозиторій на npm workspaces + Turborepo:

```
apps/
  web/          # Vite + React + TypeScript (основний вебзастосунок, i18next, Prisma)
  mobile/       # Expo + React Native
packages/
  config/       # Фіча-флаги та динамічна віддалена конфігурація
  contracts/    # Solidity 0.8.24, Hardhat, Ignition, OpenZeppelin, LayerZero
  core/         # Спільні типи, утиліти, middleware, web3
  matching/     # Алгоритми матчингу, фільтри, ранжування
  p2p/          # Мережування libp2p (gossipsub) + Nostr
  storage/      # IPFS, Arweave, Lit Protocol
docs/           # Архітектура, токеноміка, дорожня карта, FAQ
```

Ключові смарт-контракти: `EVOLVE.sol` (ERC-20), `ProfileNFT.sol` (ERC-721), `TrustScore.sol`, `Voting.sol`, `Evolve2Earn.sol` (емодзі-подарунки + нагороди), `Governance.sol`, `BondManager.sol` (зачаття та поліандрічне зачаття), `EvolveFund.sol`, `VerificationRegistry.sol`, `DNAVerification.sol`, ERC-4337 `SmartAccountFactory` + `Paymaster`, а також `TimelockController` від OpenZeppelin.

Деталі: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) · [docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md) · [docs/TOKENOMICS.md](docs/TOKENOMICS.md)

## Дорожня карта

У роботі: підготовка вебзастосунку до продакшену. Заплановано: ончейн-реєстр лабораторій і сертифікація тестів, адаптер реального поштового провайдера для отримання лабораторних звітів, ончейн-верифіковані атестації в профілях, **trustless `RewardVault`** з керованою голосуванням емісією ([дизайн](docs/REWARD-VAULT-PLAN.md)), **публічний продаж токенів**, оновлення вестинг-гаманця для алокації засновника та забезпечення DEX-ліквідності (зараз заблоковано — потрібні mainnet-розгортання токена). Мультимережеве розширення (Arbitrum, Avalanche та інші EVM-мережі) — після стабілізації на тестовій мережі.

Повний список: [docs/ROADMAP.md](docs/ROADMAP.md).

## Початок роботи (розробникам)

Вимоги: **Node.js 20+** та npm 10.x.

```bash
# Клонувати і встановити всі workspace
git clone https://github.com/Lilit-Moonlit/Evolve.git
cd Evolve
npm install

# Вебзастосунок (Vite dev-сервер на http://localhost:3000)
cd apps/web
npm run dev
npm test                # набір тестів vitest

# Смарт-контракти
cd packages/contracts
npm run compile         # hardhat compile
npm test                # набір тестів hardhat
npm run deploy:local    # розгорнути всі контракти в локальній мережі Hardhat
```
