# EVOLVE

**Знайомства, зачаття та перевірка здоров'я — приватність за замовчуванням, верифікація там, де це важливо.**

EVOLVE — це open-source децентралізована платформа для верифікованих інтимних знайомств: дейтинг, зачаття та анонімна сумісність за ІПСШ/ДНК. Ви входите власним крипто-гаманцем (Sign-In with Ethereum) — без номера телефону, без email, без KYC — а доступ до акаунта можете відновити через ончейн-DNA-зобов'язання. Дані про здоров'я залишаються вашими: результати аналізів парсяться автоматично, індивідуальні статуси патогенів **ніколи** нікому не показуються, а матчинг використовує лише анонімні вердикти сумісності (Safe / Compatible / Caution / Risk). Чат працює однорангово через libp2p і Nostr (з HTTP-фолбеком для зручності), а додаток має полегшений публічний фасад «Safety Mode» та окремий Companion Mode для оцінки результатів ІПСШ-тестів.

> **Статус: рання альфа-версія.** EVOLVE активно розробляється і не є завершеним продуктом.
> Смарт-контракти розгорнуті **лише в тестовій мережі Ethereum Sepolia**.
> **Mainnet-розгортання, DEX, ліквідності та публічного продажу токенів немає** — і ми їх не обіцяємо.
> Функціональність може змінюватися або ламатися в будь-який момент. Нічого тут не є фінансовою порадою чи інвестиційною пропозицією.

## Що і чому

Звичайні дейтинг-платформи вимагають віддати їм номер телефону, email, фото та інтимні деталі здоров'я в централізовану базу. EVOLVE починає з протилежної засади: приватність за замовчуванням, самозбереження (self-custody) і відсутність єдиної точки відмови. Ключові цінності:

- **Приватність за замовчуванням** — дані про здоров'я не розкриваються; лише анонімні вердикти.
- **Стійкість до банів** — P2P-повідомлення насамперед, децентралізоване сховище (IPFS / Arweave), мультимережева архітектура, без хардкодених доменів.
- **Самозбережена ідентичність** — ваш гаманець є вашим логіном; відновлення через ДНК замість email/телефону.
- **Без KYC** — для користування платформою не потрібні документи, телефон чи email.

Повний виклад: [docs/WHAT-AND-WHY.md](docs/WHAT-AND-WHY.md) (англійською).

## Ключові можливості

### Ідентичність і приватність

- **Вхід через гаманець (SIWE)** (MetaMask та інші EVM-гаманці) — стійкий до цензури запасний шлях.
- **Відновлення акаунта через ДНК** — результат ДНК-тесту хешується (SHA-256, ончейн-зобов'язання `bytes32`) і може відновити доступ без телефону та email.
- **Абстракція акаунта (ERC-4337)** — смарт-акаунти й пеймастер для безгазового онбордингу; SIWE залишається доступним завжди.

### Анонімна сумісність за здоров'ям

- Завантаження результатів ІПСШ-тестів як текст або PDF (витяг текстового шару з OCR-фолбеком для сканованих сторінок).
- Парсер розпізнає 8 патогенів: ВІЛ-1/2, сифіліс, хламідіоз, гонорея, ВПГ-1, ВПГ-2, гепатит B, гепатит C (формати звітів англійською, українською та російською).
- **Індивідуальний статус патогенів ніколи не показується іншим користувачам.** У профілях лише анонімний вердикт: **Safe / Compatible / Caution / Risk**.
- Ончейн-записи ДНК-верифікації (`DNAVerification.sol`) забезпечують відновлення та верифікацію.

### Профілі, пошук і спілкування

- Фільтри пошуку: «Що ви шукаєте» (знайомства / зачаття / поліандрічне зачаття / здача ІПСШ-тестів), «Кого ви шукаєте» (чоловіки, жінки, пари), каскадні селекти країна → місто, «може прибути до моєї країни» зі списками країн, колір шкіри, перевага щодо тестування, лише ІПСШ-сумісні.
- Майстер онбордингу: вік (можна приховати), мови, біо, фото.
- **Приватність фото**: фото за замовчуванням розмите; власник надає перегляд на 15 секунд або постійний — на запит або проактивно. Перегляд безкоштовний.
- **P2P-чат** через libp2p (gossipsub) + Nostr, з фолбеком на HTTP API.

### Режими зачаття

- **Режим 2 — Pregnancy Bond**: жінка створює бонд, чоловік стейкає EVOLVE (≥ 100 у поточній тестовій збірці), обидва підтверджують; після підтвердженої вагітності та батьківства стейк переходить жінці.
- **Режим 3 — Cryptic Choice**: жінка відкриває 48-годинну сесію, чоловіки приєднуються стейком; вона обирає батька — його стейк повертається, решта розподіляється: 90% їй / 10% обраному батькові.

### Лабораторії та верифікація

- **Потік лабораторій-партнерів**: лабораторії реєструються як партнери, верифікують пацієнтів через QR-код і розпізнавання обличчя, додають ІПСШ-звіти (PDF/текст з OCR-витягом).
- **Companion Mode**: окремий потік для оцінки результатів ІПСШ-тестів без реєстрації на дейтинг-платформі.
- **Safety Mode** (`VITE_PRODUCT_MODE=safety`): обмежений публічний фасад (статус ІПСШ, публічні посилання профілів, перевірки сумісності), який продовжує працювати, навіть якщо дейтинг/зачаття-функції обмежать у якоїсь юрисдикції чи апл-сторі.

### Токен EVOLVE (лише тестова мережа)

- ERC-20, максимальна емісія 8 000 000 000 EVOLVE, адмін-дії під 48-годинним TimelockController.
- **Економіка емодзі-подарунків**: подарунок коштує 1 EVOLVE, який розподіляється пропорційно між власниками наявних подарунків — безстрокова модель доходу для тримачів; подарунки можна передавати.
- **EvolveFund**: чоловічий стейкінг (мін 15 EVOLVE, блокування 30 днів), який враховується у вагі управління; жінки використовують баланс гаманця.
- **Нагороди за верифікацію**: 1 EVOLVE верифікованому користувачу та 1 EVOLVE лабораторії, що підтвердила, при верифікації ІПСШ/ДНК (плюс лімітований тестовий faucet).
- Вага голосу в управлінні поєднує рекурсивну репутацію (8 голосів, глибина 3), частку дітей/батьківства та застейкані або просто тримані EVOLVE.
- Інтеграція **LayerZero OFT** для майбутніх мультичейн-переводів EVOLVE (залежності підключені; поки що ніде, крім Sepolia, не розгорнуто).

### Платформа

- Вебзастосунок (встановлюваний як PWA) та мобільний додаток на Expo/React Native.
- Інтерфейс перекладено **34 мовами**.
- Готовність до мультимереж: 18 конфігурацій EVM-мереж (Arbitrum і Avalanche — плановані основні L2; **ще не розгорнуті**).

## Архітектура і технологічний стек

Монорепозиторій на npm workspaces + Turborepo:

```
apps/
  web/          # Vite + React + TypeScript (основний вебзастосунок, i18next, Prisma)
  mobile/       # Expo + React Native
packages/
  config/       # Фіча-флаги та динамічна віддалена конфігурація
  contracts/    # Solidity 0.8.24, Hardhat, Ignition, OpenZeppelin, LayerZero
  core/         # Спільні типи, утиліти, middleware, web3
  matching/     # Алгоритми матчингу, фільтри, ранжування
  p2p/          # Мережування libp2p (gossipsub) + Nostr
  storage/      # IPFS, Arweave, Lit Protocol
docs/           # Архітектура, токеноміка, дорожня карта, FAQ
```

Ключові смарт-контракти: `EVOLVE.sol` (ERC-20), `ProfileNFT.sol` (ERC-721), `TrustScore.sol`, `Voting.sol`, `Evolve2Earn.sol` (емодзі-подарунки + нагороди), `Governance.sol`, `BondManager.sol` (режими 2 і 3), `EvolveFund.sol`, `VerificationRegistry.sol`, `DNAVerification.sol`, ERC-4337 `SmartAccountFactory` + `Paymaster`, а також `TimelockController` від OpenZeppelin.

Деталі: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) · [docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md) · [docs/TOKENOMICS.md](docs/TOKENOMICS.md)

## Дорожня карта

У роботі: підготовка вебзастосунку до продакшену. Заплановано: ончейн-реєстр лабораторій і сертифікація тестів, адаптер реального поштового провайдера для отримання лабораторних звітів, ончейн-верифіковані атестації в профілях, оновлення вестинг-гаманців для алокацій засновників/розробників, забезпечення DEX-ліквідності (зараз заблоковано — потрібні mainnet-розгортання токена). Мультимережеве розширення (Arbitrum, Avalanche та інші EVM-мережі) — після стабілізації на тестовій мережі.

Повний список: [docs/ROADMAP.md](docs/ROADMAP.md).

## Початок роботи (розробникам)

Вимоги: **Node.js 20+** та npm 10.x.

```bash
# Клонувати і встановити всі workspace
git clone https://github.com/Lilit-Moonlit/Evolve.git
cd Evolve
npm install

# Вебзастосунок (Vite dev-сервер на http://localhost:3000)
cd apps/web
npm run dev
npm test                # набір тестів vitest

# Смарт-контракти
cd packages/contracts
npm run compile         # hardhat compile
npm test                # набір тестів hardhat
npm run deploy:local    # розгорнути всі контракти в локальній мережі Hardhat
```
