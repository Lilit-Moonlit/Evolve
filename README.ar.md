# EVOLVE

**مواعدة وإنجاب وصحة موثَّقة — الخصوصية افتراضيًا، والثقة حيث تهمّ فعلًا.**

EVOLVE منصة مفتوحة المصدر لامركزية، مخصّصة لمن سئم تسليم رقم هاتفه ووجهه وأخصّ بياناته الصحية لقاعدة بيانات يملكها شخص آخر. تسجّل الدخول بمحفظة العملات المشفّرة الخاصة بك — بلا هاتف ولا بريد إلكتروني ولا KYC — ويمكنك استعادة حسابك عبر التزام DNA مسجَّل على السلسلة. تبقى بياناتك الصحية ملكك: تُحلَّل نتائج الفحوص تلقائيًا، وحالات مسبّبات الأمراض الفردية **لا تُعرَض أبدًا** لأي كان، ويعتمد التطابق على أحكام توافق مجهولة الهوية فقط (آمن / متوافق / حذر / خطر). تعمل المحادثة بنظام ندّ للندّ عبر libp2p وNostr، مع بديل HTTP للراحة. وتتجه الهدايا والتحويلات نحو السرّية الكاملة: هدايا المرسل الخاصّة متاحة اليوم، فيما تقع محفظة Railgun المحمية ونموذج Aztec الأولي للمعرفة الصفرية على خارطة الطريق (اطّلع على قسم [الخصوصية والمعاملات السرّية](#privacy--confidential-transactions)).

> **الحالة — وضع تجريبي، قيد التطوير النشط.**
> المواعدة والإنجاب والتحقق الصحي وتدفّق المختبر والمحادثة عبر P2P ورمز EVOLVE والحوكمة — كلها منفَّذة وتعمل في **عرض توضيحي محلي** — والتطبيق **غير منشور للعامة بعد**. وما زال أمامنا: **النشر على الشبكة الرئيسية وسيولة DEX**، إضافة إلى **بيع عام مخطَّط له** (اطّلع على [رمز EVOLVE](#the-evolve-token-testnet-only)).
> العقود الذكية منشورة على **شبكة Ethereum Sepolia الاختبارية فقط**. ولا يُعدّ أي شيء هنا نصيحة مالية أو عرضًا استثماريًا.

> **هل تجد EVOLVE مفيدًا؟ ادعم التطوير — فكل تبرع يذهب إلى الكود وشراكات المختبرات والاستضافة والترجمة → [DONATE.md](DONATE.md).**

## لا شيء تخشاه

بُني EVOLVE حول الأسئلة التي يطرحها الناس فعلًا قبل منح ثقتهم لمنصة كهذه.

| ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| «ستُسرَّب بياناتي الصحية.»                | نتائج مسبّبات الأمراض الفردية **لا تُعرَض أبدًا** لأي شخص — فقط حكم مجهول الهوية: آمن / متوافق / حذر / خطر.                                                                 |

## ماذا ولماذا

تطلب تطبيقات المواعدة التقليدية منك مقايضة رقم هاتفك وبريدك الإلكتروني وصورك وتفاصيلك الصحية الحميمة بقاعدة بيانات مركزية — ثم أن تثق بتلك القاعدة إلى الأبد. ينطلق EVOLVE من الفرضية المعاكسة: **الخصوصية افتراضيًا، والحفظ الذاتي، ولا نقطة فشل واحدة**.

- **الخصوصية افتراضيًا** — لا تُكشف البيانات الصحية أبدًا؛ فقط أحكام مجهولة الهوية.
- **مقاومة الحظر** — مراسلة P2P أولًا، وتخزين لامركزي، وتصميم متعدد الشبكات، وبلا نطاقات مثبَّتة في الكود.
- **هوية ذاتية الحفظ** — محفظتك هي تسجيل دخولك؛ واستعادة قائمة على DNA بدلًا من البريد الإلكتروني أو الهاتف.
- **لا بوابة KYC** — لا يُشترط لاستخدام المنصة تقديم هوية حكومية أو هاتف أو بريد إلكتروني.

اطّلع على التسويغ الكامل في [docs/WHAT-AND-WHY.md](docs/WHAT-AND-WHY.md).

## صحة يمكنك الوثوق بها فعلًا

- ارفع اختبار STD كنص خام أو بملف PDF (استخراج طبقة النص، مع بديل OCR للمسوحات الضوئية).
- يعرف المحلّل 8 مسبّبات للأمراض: HIV-1/2، والزهري، والكلاميديا، والسيلان، وHSV-1، وHSV-2، والتهاب الكبد B، والتهاب الكبد C — بصيغ التقارير الإنجليزية والأوكرانية والروسية.
- **حالة مسبّب المرض الفردي لا تُعرض أبدًا للمستخدمين الآخرين.** الملفات الشخصية لا تُظهر سوى الحكم المجهول: **آمن / متوافق / حذر / خطر**.
- تسجّلات DNA على السلسلة (`DNAVerification.sol`) تشغّل الاستعادة والتحقق.

### المختبرات الشريكة — برهان، لا وعود

ادخل إلى مختبر شريك واعرض رمز QR الخاص بك. يمسحه المختبر، ويؤكد هويتك عبر **مطابقة الوجه** (حتى لا يستطيع غيرك استلام نتيجتك)، ويرفق تقرير STD — ملف PDF أو مسحًا ضوئيًا أو نصًا، حتى لو كان OCR رديئًا. النتيجة موقَّعة من مختبر حقيقي لا منك، فيرى الآخرون **حقيقة موثَّقة** بدل كلمتك. وكل عملية تحقق مؤكَّدة تدفع **1 EVOLVE للمريض و1 EVOLVE للمختبر** — فللطرفين سبب ليكونا صادقين. وما تزال مسبّبات الأمراض الفردية لا تُعرض أبدًا لأي كان.

## العثور على شخص

- فلاتر البحث: «ماذا تبحث عنه» (مواعدة / إنجاب / إنجاب بتعدد الأزواج / فحص STD)، و«من تبحث عنه» (رجال، نساء، أزواج)، وقوائم اختيار متتالية من الدولة إلى المدينة، وخيار «يمكنه السفر إلى بلدك» مع قوائم لكل دولة، ولون البشرة، وتفضيل الفحص، والمتوافقون في STD فقط.
- معالج الانضمام الأولي: العمر (قابل للإخفاء)، واللغات، ونبذة تعريفية، وصورة.
- **محادثة P2P** عبر libp2p (gossipsub) + Nostr، مع بديل HTTP API.

## الإنجاب

طريقتان لتخطيط طفل، وكلتاهما تقومان على الفكرة نفسها: النية الحقيقية يُبرهَن عليها برهان مالي حقيقي بـ EVOLVE — لا بالوعود أبدًا. يكمن التزام الرجل في وديعته في EvolveFund (من 15 EVOLVE، مقفلة 30 يومًا على الأقل)، ويمكن للمرأة تحديد حدها الأدنى الخاص لوديعة الرجال الذين يصلون إليها.

**الإنجاب.** المرأة هي من تقود: تدعو رجلًا بعينه وتسمّيه في رابطة. يشترط أن تكون لديه وديعة نشطة في EvolveFund؛ وعندما يؤكد الطرفان، تُقفل الوديعة ويبدأ العدّ التنازلي. يُبلَّغ عن الحمل بين 14 و30 يومًا من التأكيد، وتُؤخذ اختبارات STD وDNA للطرفين في اللقاء نفسه — نتائج STD الحديثة مهمة، أما DNA فلا يشيخ. وبمجرد تأكيد الأبوّة، تنتقل وديعة الرجل إلى المرأة؛ وإن لم تُؤكَّد، فتُفرَج عنها ببساطة وتعود إليه. لا ينتقل أي شيء من يد إلى يد قبل حسم الوقائع.

**الإنجاب بتعدد الأزواج.** الاختيار لها، ويبقى خاصًا. تفتح جلسة تدوم 48 ساعة — دون وديعة خاصة بها (يمكنها إضافة واحدة للسمعة فقط إن شاءت). يمكن للرجال أصحاب الودائع النشطة الانضمام — حتى 50 رجلًا — والتأكيد، وهو ما يقفل رهاناتهم. بعد أربعة عشر يومًا من إغلاق الجلسة، يُختار الأب، فيستعيد وديعته مضافًا إليها مكافأة من الصندوق: ضعف وديعته و1 EVOLVE عن كل مشارك آخر. أما الرجال غير المختارون فيخسرون رهاناتهم — 90% إلى المرأة و10% إلى الأب المختار. هي لا تخاطر بشيء ولا يمكنها إلا الكسب؛ والرجال يضعون رهاناتهم مقابل حق أن يُختاروا.

## الخصوصية والمعاملات السرّية

الخصوصية هي الوضع الافتراضي — ويعمل EVOLVE على خارطة طريق نحو تحويلات على السلسلة سرّية تمامًا.

- **هدايا خاصة** — أرسل وردة 🌹 أو صبارًا 🌵 (1 EVOLVE) واختر من يستطيع رؤية أنك المرسل: _عن جهار_، أو _مجهول للجميع عدا المستلم_، أو _مجهول تمامًا_. في الوضعين المجهولين تنتقل الهدية بصيغة قسيمة أحادية الاستخدام يطالب بها المستلم بمحفظته الخاصة، فلا يظهر المرسل على السلسلة أبدًا. (إخفاء هوية المرسل اليوم بمستوى عادي: يمكن ربط معاملة التمويل عبر الوقت والمبلغ.)
- **محفظة Railgun المحمية** — محفظة خاصة مفعَّلة بعلم ميزة (`VITE_RAILGUN_ENABLED`، معطلة افتراضيًا) تخفي المبالغ والعناوين باستخدام تجمّع المعرفة الصفرية الحيّ الخاص بـ Railgun. هذا هو الطريق إلى إخفاء هوية المرسل الحقيقي.
- **نموذج Aztec الأولي** — منطق التحويل الخاص والرابطة الخاصة نفسه، معبَّرًا عنه بدارات Noir بمعرفة صفرية، ومحفوظ خلف بوابة صريحة حتى يصبح Aztec جاهزًا للإنتاج. اطّلع على [docs/AZTEC-PROTOTYPE.md](docs/AZTEC-PROTOTYPE.md).
- **نموذج المحفظتين** — محفظة الرهان العامة تشارك في الحوكمة؛ أما المحفظة الخاصة المحمية ف**مستبعَدة** عمدًا من وزن الحوكمة، إبقاءً للخصوصية وقوة التصويت منفصلتين.

التفاصيل: [docs/RAILGUN-INTEGRATION.md](docs/RAILGUN-INTEGRATION.md) · [docs/SHIELDED-STAKES-DESIGN.md](docs/SHIELDED-STAKES-DESIGN.md) · [docs/AZTEC-PROTOTYPE.md](docs/AZTEC-PROTOTYPE.md).

## رمز EVOLVE (على الشبكة الاختبارية فقط)

- ERC-20، بحد أقصى للإصدار **8,000,000,000 EVOLVE**. الإجراءات الإدارية محكومة بـ `TimelockController` مهلته 48 ساعة.
- **توزيع الإصدار المخطَّط له** — مصمَّم بحيث يعمل الإصدار بأكمله تقريبًا لخدمة المستخدمين، لا لخدمة المطلّعين من الداخل:

| الغرض                                                 |        EVOLVE |
| ----------------------------------------------------- | ------------: |
| المؤسسون والفريق (راتب / مكافأة)                      |    25,000,000 |
| احتياطي DEX (مستقبلًا)                                |     4,000,000 |
| بيع عام (مخطَّط له)                                   |     5,000,000 |
| احتياطي المكافآت — المختبرات والمرضى والأمهات والآباء | 7,966,000,000 |

- **بيع عام مخطَّط له** — 5,000,000 EVOLVE يبيعها التطبيق بسعر **0.8 دولار لكل رمز**، والدفع بأي رمز تدعمه التطبيق؛ وتذهب العائدات إلى تمويل التطوير. _(مخطَّط له — لم ينطلق بعد.)_
- **إصدار لا يتطلب ثقة (مخطَّط له)** — سيُقفل احتياطي المكافآت البالغ نحو 7,966,000,000 في `RewardVault` غير قابل للتصفير: لا يُفرَج عنه إلا تدريجيًا عبر مكافآت المختبرات والمرضى والأمهات والآباء، ويتطلب تغيير القواعد تصويتًا في الحوكمة. حتى المؤسس لا يستطيع السحب منه. التصميم: [docs/REWARD-VAULT-PLAN.md](docs/REWARD-VAULT-PLAN.md).
- **اقتصاد هدايا الإيموجي** — تكلّف الهدية 1 EVOLVE تُقسَّم بالتناسب بين مالكي الهدايا الحاليين؛ نموذج إيراد دائم، والهدايا قابلة للتحويل.
- **EvolveFund** — رهان للرجال (بحد أدنى 15 EVOLVE، وقفل 30 يومًا) يُحتسب في وزن الحوكمة؛ أما النساء فيستخدمن رصيد محفظتهن.
- **مكافآت التحقق** — 1 EVOLVE للمستخدم الموثَّق و1 EVOLVE للمختبر المؤكِّد عن كل عملية تحقق STD/DNA (إضافة إلى صنبور محدود المعدل).
- **الحوكمة** — يجمع وزن التصويت بين السمعة التكرارية (8 أصوات، بعمق 3)، ونسبة الأطفال/الأبوّة، وEVOLVE المراهَن به أو المحتفَظ به.
- تكامل **LayerZero OFT** لتحويلات EVOLVE متعددة السلاسل مستقبلًا (التبعيات جاهزة؛ ولم يُنشر أي شيء خارج Sepolia حتى الآن).

## المعمارية والتقنيات المستخدمة

مستودع موحَّد (Monorepo) يُدار بـ npm workspaces + Turborepo:

```
apps/
  web/          # Vite + React + TypeScript (main web app, i18next, Prisma)
  mobile/       # Expo + React Native
packages/
  config/       # Feature flags & dynamic remote configuration
  contracts/    # Solidity 0.8.24, Hardhat, Ignition, OpenZeppelin, LayerZero
  core/         # Shared types, utilities, middleware, web3
  matching/     # Matching algorithms, filters, ranking
  p2p/          # libp2p (gossipsub) + Nostr networking
  storage/      # IPFS, Arweave, Lit Protocol
docs/           # Architecture, tokenomics, roadmap, FAQ
```

أبرز العقود الذكية: `EVOLVE.sol` (ERC-20)، و`ProfileNFT.sol` (ERC-721)، و`TrustScore.sol`، و`Voting.sol`، و`Evolve2Earn.sol` (هدايا الإيموجي + المكافآت)، و`Governance.sol`، و`BondManager.sol` (الإنجاب والإنجاب بتعدد الأزواج)، و`EvolveFund.sol`، و`VerificationRegistry.sol`، و`DNAVerification.sol`، وERC-4337 `SmartAccountFactory` + `Paymaster`، و`TimelockController` من OpenZeppelin.

## خارطة الطريق

قيد التنفيذ حاليًا: جاهزية تطبيق الويب للإنتاج. ومخطَّط له: سجل مختبرات على السلسلة واعتماد الفحوصات، ومحوّل بريد حقيقي لاستقبال تقارير المختبر، وشهادات موثَّقة على السلسلة في الملفات الشخصية، و**RewardVault** غير القابل للتصفير بإصدار محكوم بالحوكمة ([التصميم](docs/REWARD-VAULT-PLAN.md))، و**البيع العام للرمز**، وتحديث جدول إطلاق حصة المؤسس، وتوفير سيولة DEX (محجوب حاليًا — إذ يتطلب نشر الرمز على الشبكة الرئيسية). وعلى جبهة الخصوصية، اكتملت هدايا المرسل الخاصّة، بينما تبقى محفظة Railgun المحمية وترحيل الروابط الخاصة إلى Aztec خلف بوابات الفحص المذكورة في [docs/ROADMAP.md](docs/ROADMAP.md) و[docs/AZTEC-PROTOTYPE.md](docs/AZTEC-PROTOTYPE.md). ويأتي التوسع متعدد الشبكات (Arbitrum وAvalanche وسلاسل EVM أخرى) بعد تحصين الشبكة الاختبارية.

القائمة الكاملة: [docs/ROADMAP.md](docs/ROADMAP.md).

## البدء (للمطورين)

المتطلبات: **Node.js 20+** وnpm 10.x.

```bash
# Clone and install all workspaces
git clone https://github.com/Lilit-Moonlit/Evolve.git
cd Evolve
npm install

# Web app (Vite dev server on http://localhost:3000)
cd apps/web
npm run dev
npm test                # vitest suite

# Smart contracts
cd packages/contracts
npm run compile         # hardhat compile
npm test                # hardhat test suite
npm run deploy:local    # deploy all contracts to an in-process Hardhat network
```
