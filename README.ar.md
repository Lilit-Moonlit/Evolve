# EVOLVE

**مواعدة وإنجاب وصحة موثّقة — الخصوصية افتراضًا، والثقة حيث تهم.**

EVOLVE منصة مفتوحة المصدر ولامركزية، مخصّصة لمن سئم تسليم رقم هاتفه ووجهه وأخصّ بياناته الصحية لقاعدة بيانات تخصّ شخصًا آخر. تسجّل الدخول بمحفظة العملات المشفّرة الخاصة بك — بلا هاتف، بلا بريد إلكتروني، بلا KYC — ويمكنك استعادة حسابك عبر التزام DNA على السلسلة. بياناتك الصحية تبقى ملكك: تُحلَّل نتائج الفحوص تلقائيًا، ولا تُعرض حالات مسبّبات الأمراض الفردية لأي شخص **أبدًا**، ويعتمد التطابق على أحكام توافق مجهولة الهوية فقط (Safe / Compatible / Caution / Risk). تعمل المحادثة من نظير إلى نظير عبر libp2p وNostr، مع بديل HTTP للراحة.

> **الحالة — المنصة تعمل اليوم؛ الشبكة الرئيسية وDEX هما الخطوة التالية.**
> المواعدة والإنجاب والتحقق الصحي وتدفق المختبر والمحادثة P2P ورمز EVOLVE والحوكمة — كلها تعمل. ما زال أمامنا: **نشر على الشبكة الرئيسية وسيولة DEX**، إضافة إلى **طرح عام مخطّط له** (انظر [رمز EVOLVE](#رمز-evolve-على-شبكة-الاختبار-فقط)).
> العقود الذكية منشورة **على شبكة Ethereum Sepolia الاختبارية فقط**. لا شيء هنا يُعد نصيحة مالية أو عرض استثمار.

> **هل تجد EVOLVE مفيدًا؟ ادعم التطوير — كل تبرع يذهب إلى الكود وشراكات المختبرات والاستضافة والترجمة → [DONATE.md](DONATE.md)**

## لا شيء تخشاه

بُنيت EVOLVE حول الأسئلة التي يطرحها الناس فعلًا قبل الوثوق بمنصة كهذه.

| القلق                                | ما تفعله EVOLVE بالفعل حيال ذلك                                                                                                                  |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| «ستسرّب بياناتي الصحية.»             | نتائج مسبّبات الأمراض الفردية لا تُعرض لأي شخص **أبدًا** — فقط حكم مجهول الهوية: Safe / Compatible / Caution / Risk.                             |
| «ستتناثر صوري في مكان ما.»           | الصور ضبابية افتراضيًا. يمنح المالك عرضًا لمدة **15 ثانية** أو **دائمًا** — بناءً على طلب أو بمبادرة منه. المشاهدة مجانية.                       |
| «سأضطر لتسليم هويتي أو هاتفي.»       | تسجيل الدخول عبر المحفظة (SIWE). بلا هاتف، بلا بريد إلكتروني، بلا KYC. تعمل الاستعادة عبر التزام DNA على السلسلة.                                |
| «هو أو هي تكذب بشأن السلامة الصحية.» | النتائج **موثّقة من مختبر** (QR + مطابقة الوجه)، وفحوص الثنائي تُؤخذ **أثناء اللقاء نفسه** — نتائج STD الحديثة هي ما يهم، أما DNA فلا «يشيخ».    |
| «هل سيأخذ أحدهم مالي ويختفي؟»        | يقوم الإنجاب على رهان حقيقي معرّض للخطر: لا تتحرك وديعة الرجل إلا عندما تُثبَت الأبوة؛ وإلا تُعاد إليه ببساطة.                                   |
| «هل الرمز مجرد ضخّ وتفريغ؟»          | لا يوجد بيع قائم اليوم؛ الكود مفتوح (MIT)؛ ويُخطَّط لإقفال الاحتياطي غير المتداول في **خزنة غير قابلة للتصريف** لا يستطيع حتى المؤسس السحب منها. |
| «هل يمكن إغلاق المنصة أو حظرها؟»     | المراسلة من نظير إلى نظير أولًا، وتخزين لامركزي (IPFS / Arweave)، و18 تهيئة لشبكات EVM، وبلا نطاق مثبَّت في الكود.                               |

## ماذا ولماذا

تطلب منك تطبيقات المواعدة التقليدية مقايضة رقم هاتفك وبريدك الإلكتروني وصورك وتفاصيلك الصحية الحميمة بقاعدة بيانات مركزية — ثم عليك الوثوق بتلك القاعدة إلى الأبد. تنطلق EVOLVE من الفرضية المعاكسة: **الخصوصية افتراضيًا، والحفظ الذاتي، ولا نقطة فشل وحيدة**.

- **الخصوصية افتراضيًا** — بيانات الصحة لا تُكشف أبدًا؛ فقط أحكام مجهولة الهوية.
- **مقاومة الحظر** — مراسلة من نظير إلى نظير أولًا، تخزين لامركزي، تصميم متعدد الشبكات، بلا نطاقات مثبّتة في الكود.
- **هوية بحفظ ذاتي** — محفظتك هي تسجيل دخولك؛ استعادة قائمة على DNA بدلًا من البريد أو الهاتف.
- **لا توجد بوابة KYC** — لا حاجة إلى هوية حكومية أو هاتف أو بريد إلكتروني لاستخدام المنصة.

اقرأ المبرّر الكامل في [docs/WHAT-AND-WHY.md](docs/WHAT-AND-WHY.md).

## صحة يمكنك الوثوق بها فعلًا

- ارفع فحص STD كنص خام أو PDF (استخراج طبقة النص، مع بديل OCR للمسوحات الضوئية).
- يعرف المحلّل 8 مسبّبات للأمراض: HIV-1/2، الزهري، المتدثّرة، السيلان، HSV-1، HSV-2، التهاب الكبد B، التهاب الكبد C — بصيغ تقارير إنجليزية وأوكرانية وروسية.
- **حالة مسبّب المرض الفردي لا تُعرض للمستخدمين الآخرين أبدًا.** تعرض الملفات الشخصية فقط الحكم المجهول الهوية: **Safe / Compatible / Caution / Risk**.
- سجلات DNA على السلسلة (`DNAVerification.sol`) تدعم الاستعادة والتحقق.

### المختبرات الشريكة — برهان لا وعود

ادخل إلى مختبر شريك واعرض رمز QR. يمسحه المختبر، ويؤكد هويتك عبر **مطابقة الوجه** (حتى لا يستلم نتيجتك أحد سواك)، ويُرفق تقرير STD — بصيغة PDF أو مسح ضوئي أو نص، حتى لو كانت جودة OCR رديئة. النتيجة موقّعة من مختبر حقيقي لا منك، فيرى الآخرون **حقيقة موثّقة** بدل كلمتك. وكل تحقق مؤكد يدفع **1 EVOLVE للمريض و1 EVOLVE للمختبر** — لكلا الطرفين سبب للصدق. ومع ذلك لا تُعرض مسبّبات الأمراض الفردية لأي شخص أبدًا.

## إيجاد شخص ما

- فلاتر البحث: «ماذا تبحث عنه» (مواعدة / إنجاب / إنجاب بتعدد الأزواج / فحوص STD)، «عمّن تبحث» (رجال، نساء، أزواج)، قوائم اختيار متتالية للدولة ثم المدينة، «يمكنه السفر إلى بلدك» مع قوائم لكل دولة، لون البشرة، تفضيل الفحص، التوافق مع STD فقط.
- معالج التهيئة الأولية: العمر (قابل للإخفاء)، اللغات، نبذة تعريفية، صورة.
- **محادثة P2P** عبر libp2p (gossipsub) + Nostr، مع بديل HTTP API.

## الإنجاب

طريقتان لتخطيط طفل، وكلتاهما تقومان على الفكرة نفسها: النية الحقيقية تُظهرها حصّة حقيقية في EVOLVE — لا الوعود أبدًا. التزام الرجل يكمن في وديعته في EvolveFund (من 15 EVOLVE، مقفلة 30 يومًا على الأقل)، ويمكن للمرأة تحديد الحد الأدنى لوديعة الرجال الذين يصلون إليها.

**الإنجاب.** المرأة تقود: تدعو رجلًا بعينه وتسمّيه في رابطة (bond). يحتاج إلى وديعة EvolveFund سارية؛ وعندما يؤكّد الطرفان تُقفل الوديعة ويبدأ العدّ التنازلي. يُبلَّغ عن الحمل بين 14 و30 يومًا بعد التأكيد، وتُؤخذ فحوصات STD وDNA للثنائي في اللقاء نفسه — نتائج STD الحديثة هي ما يهم، أما DNA فلا يشيخ. متى ثبتت الأبوة انتقلت وديعة الرجل إلى المرأة؛ وإن لم تثبت، تُحرَّر الوديعة ببساطة وتعود إليه. لا شيء يغيّر أصحابه قبل أن تُحسم الوقائع.

**الإنجاب بتعدد الأزواج.** الاختيار لها وتبقى خصوصيًا. تفتح جلسة تدوم 48 ساعة — بلا وديعة منها (يمكنها إضافة واحدة للسمعة فقط إن أرادت). يمكن للرجال ذوي الوديعة السارية الانضمام — حتى 50 — والتأكيد، ما يقفل حصّتهم. بعد أربعة عشر يومًا من إقفال الجلسة يُختار الأب. يستعيد وديعته مضافًا إليها مكافأة من الصندوق: ضعف وديعته و1 EVOLVE عن كل مشارك آخر. أما الرجال غير المختارون فيخسرون حصّتهم — 90% للمرأة و10% للأب المختار. هي لا تخاطر بشيء ولا يمكنها إلا الكسب؛ والرجال يضعون حصّتهم مقابل حقّ أن يُختاروا.

## رمز EVOLVE (على شبكة الاختبار فقط)

- ERC-20، الحد الأقصى للعرض **8,000,000,000 EVOLVE**. الإجراءات الإدارية محكومة بـ`TimelockController` لمدة 48 ساعة.
- **توزيع العرض المخطّط** — مصمَّم بحيث يعمل العرض كله تقريبًا لصالح المستخدمين لا لصالح المطلّعين من الداخل:

| الغرض                                                 |        EVOLVE |
| ----------------------------------------------------- | ------------: |
| المؤسسون والفريق (راتب / مكافأة)                      |    25,000,000 |
| احتياطي DEX (مستقبلًا)                                |     4,000,000 |
| طرح عام (مخطّط)                                       |     5,000,000 |
| احتياطي المكافآت — المختبرات والمرضى والأمهات والآباء | 7,966,000,000 |

- **طرح عام مخطّط** — 5,000,000 EVOLVE تبيعها التطبيق بسعر **$0.8 للواحد**، والدفع بأي رمز يدعمه التطبيق؛ وتذهب الحصيلة لتمويل التطوير. _(مخطّط — ليس قائمًا بعد.)_
- **إصدار بلا وسيط موثوق (مخطّط)** — احتياطي المكافآت البالغ ~7,966,000,000 سيُقفل في `RewardVault` غير قابل للتصريف: يُفرج عنه تدريجيًا فقط عبر مكافآت المختبرات والمرضى والأمهات والآباء، وتتطلب تغييرات القواعد تصويت حوكمة. حتى المؤسس لا يستطيع السحب منه. التصميم: [docs/REWARD-VAULT-PLAN.md](docs/REWARD-VAULT-PLAN.md).
- **اقتصاد هدايا الإيموجي** — تكلفة الهدية 1 EVOLVE، تُوزَّع تناسبيًا على مالكي الهدايا الحاليين؛ نموذج إيراد دائم، والهدايا قابلة للتحويل.
- **EvolveFund** — تجميد للرجال (بحد أدنى 15 EVOLVE، وقفل 30 يومًا) يُحتسب في وزن الحوكمة؛ النساء يستخدمن رصيد محفظتهن.
- **مكافآت التحقق** — 1 EVOLVE للمستخدم الموثَّق و1 EVOLVE للمختبر المؤكِّد في كل تحقق STD/DNA (إضافة إلى صنبور محدود المعدل).
- **الحوكمة** — يجمع وزن التصويت بين السمعة التكرارية (8 أصوات، عمق 3)، ونسبة الأطفال/الأبوة، وEVOLVE المجمَّد أو المحتفظ به.
- تكامل **LayerZero OFT** لتحويلات EVOLVE متعددة السلاسل مستقبلًا (الاعتماديات جاهزة؛ لم يُنشر شيء خارج Sepolia بعد).

## البنية والتقنيات

Monorepo يُدار بـ npm workspaces + Turborepo:

```
apps/
  web/          # Vite + React + TypeScript (main web app, i18next, Prisma)
  mobile/       # Expo + React Native
packages/
  config/       # Feature flags & dynamic remote configuration
  contracts/    # Solidity 0.8.24, Hardhat, Ignition, OpenZeppelin, LayerZero
  core/         # Shared types, utilities, middleware, web3
  matching/     # Matching algorithms, filters, ranking
  p2p/          # libp2p (gossipsub) + Nostr networking
  storage/      # IPFS, Arweave, Lit Protocol
docs/           # Architecture, tokenomics, roadmap, FAQ
```

أبرز العقود الذكية: `EVOLVE.sol` (ERC-20)، `ProfileNFT.sol` (ERC-721)، `TrustScore.sol`، `Voting.sol`، `Evolve2Earn.sol` (هدايا الإيموجي + المكافآت)، `Governance.sol`، `BondManager.sol` (الإنجاب والإنجاب بتعدد الأزواج)، `EvolveFund.sol`، `VerificationRegistry.sol`، `DNAVerification.sol`، ERC-4337 `SmartAccountFactory` + `Paymaster`، و`TimelockController` من OpenZeppelin.

التفاصيل: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) · [docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md) · [docs/TOKENOMICS.md](docs/TOKENOMICS.md)

## خارطة الطريق

جارٍ العمل: جاهزية تطبيق الويب للإنتاج. مخطّط له: سجل مختبرات على السلسلة واعتماد الفحوص، ومحوّل بريد حقيقي لاستقبال تقارير المختبر، وشهادات موثّقة على السلسلة في الملفات الشخصية، و**RewardVault بلا وسيط موثوق** بإصدار محكوم بالحوكمة ([التصميم](docs/REWARD-VAULT-PLAN.md))، و**الطرح العام للرمز**، وتحديث استحقاق الرموز لحصة المؤسس، وتوفير سيولة DEX (متوقف حاليًا — يتطلب نشر الرمز على الشبكة الرئيسية). التوسع متعدد الشبكات (Arbitrum وAvalanche وسلاسل EVM أخرى) يأتي بعد تعزيز شبكة الاختبار.

القائمة الكاملة: [docs/ROADMAP.md](docs/ROADMAP.md).

## البدء (للمطورين)

المتطلبات: **Node.js 20+** وnpm 10.x.

```bash
# Clone and install all workspaces
git clone https://github.com/Lilit-Moonlit/Evolve.git
cd Evolve
npm install

# Web app (Vite dev server on http://localhost:3000)
cd apps/web
npm run dev
npm test                # vitest suite

# Smart contracts
cd packages/contracts
npm run compile         # hardhat compile
npm test                # hardhat test suite
npm run deploy:local    # deploy all contracts to an in-process Hardhat network
```
