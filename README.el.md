# EVOLVE

**Γνωριμίες, σύλληψη και επαλήθευση υγείας — ιδιωτικότητα εκ προεπιλογής, επαλήθευση εκεί όπου μετράει.**

Το EVOLVE είναι μια αποκεντρωμένη πλατφόρμα ανοιχτού κώδικα για επαληθεύσιμες στενές σχέσεις: γνωριμίες, σύλληψη και ανώνυμη συμβατότητα STD/DNA. Συνδέεστε με το δικό σας κρυπτονομισματικό πορτοφόλι (Sign-In with Ethereum) — χωρίς αριθμό τηλεφώνου, χωρίς email, χωρίς KYC — και μπορείτε να ανακτήσετε τον λογαριασμό σας μέσω μιας δέσμευσης DNA στο blockchain. Τα δεδομένα υγείας παραμένουν δικά σας: τα εργαστηριακά αποτελέσματα αναλύονται αυτόματα, οι μεμονωμένες καταστάσεις των παθογόνων **δεν εμφανίζονται ποτέ** σε κανέναν, και το ταίριασμα βασίζεται αποκλειστικά σε ανώνυμα συμπεράσματα συμβατότητας (Safe / Compatible / Caution / Risk). Η συνομιλία λειτουργεί peer-to-peer μέσω libp2p και Nostr, με HTTP εναλλακτική λύση για ευκολία, ενώ η εφαρμογή διαθέτει μια ελαφριά δημόσια πρόσοψη «Safety Mode» καθώς και μια αυτοτελή λειτουργία «Companion Mode» για την αξιολόγηση STD τεστ.

> **Κατάσταση: πρώιμο alpha.** Το EVOLVE βρίσκεται σε ενεργή ανάπτυξη και δεν αποτελεί ολοκληρωμένο προϊόν.
> Τα έξυπνα συμβόλαια έχουν αναπτυχθεί **μόνο στο δοκιμαστικό δίκτυο Ethereum Sepolia**.
> **Δεν υπάρχει ανάπτυξη σε mainnet, δεν υπάρχει DEX, δεν υπάρχει ρευστότητα και δεν υπάρχει δημόσια πώληση token** — και τίποτα από αυτά δεν έχει υποσχεθεί.
> Οι λειτουργίες ενδέχεται να αλλάξουν ή να καταρρεύσουν ανά πάσα στιγμή. Τίποτα εδώ δεν αποτελεί χρηματοοικονομική συμβουλή ή επενδυτική προσφορά.

## Τι & Γιατί

Οι παραδοσιακές πλατφόρμες γνωριμιών σας ζητούν να παραδώσετε τον αριθμό τηλεφώνου, το email, τις φωτογραφίες και τα προσωπικά σας υγειονομικά στοιχεία σε μια κεντρική βάση δεδομένων. Το EVOLVE ξεκινά από την αντίθετη προϋπόθεση: ιδιωτικότητα εκ προεπιλογής, αυτοφύλαξη και κανένα κεντρικό σημείο αποτυχίας. Βασικές αξίες:

- **Ιδιωτικότητα εκ προεπιλογής** — τα δεδομένα υγείας δεν εκτίθενται ποτέ· μόνο ανώνυμα συμπεράσματα.
- **Αντίσταση στην απαγόρευση** — μηνύματα με προτεραιότητα P2P, αποκεντρωμένη αποθήκευση (IPFS / Arweave), σχεδιασμός πολλαπλών δικτύων, χωρίς ενσωματωμένους τομείς.
- **Ταυτότητα αυτοφύλαξης** — το πορτοφόλι σας είναι η σύνδεσή σας· ανάκτηση μέσω DNA αντί για email/τηλέφωνο.
- **Κανένα KYC εμπόδιο** — δεν απαιτείται δελτίο ταυτότητας, τηλέφωνο ή email για τη χρήση της πλατφόρμας.

Διαβάστε την πλήρη αιτιολόγηση στο [docs/WHAT-AND-WHY.md](docs/WHAT-AND-WHY.md) (στα αγγλικά).

## Βασικά Χαρακτηριστικά

### Ταυτότητα & Ιδιωτικότητα

- **Σύνδεση με πορτοφόλι μέσω SIWE** (MetaMask και άλλα πορτοφόλια EVM) — η έξοδος διαφυγής έναντι της λογοκρισίας.
- **Ανάκτηση λογαριασμού μέσω DNA** — το αποτέλεσμα του DNA τεστ σας υφίσταται κατακερματισμό (SHA-256, δεσμευμένο on-chain ως `bytes32`) και μπορεί να αποκαταστήσει την πρόσβαση χωρίς τηλέφωνο ή email.
- **Αφαίρεση λογαριασμού (ERC-4337)** — έξυπνοι λογαριασμοί και paymaster για onboarding χωρίς gas· το SIWE παραμένει πάντα διαθέσιμο.

### Ανώνυμη Συμβατότητα Υγείας

- Μεταφόρτωση αποτελεσμάτων STD τεστ ως ακατέργαστο κείμενο ή PDF (εξαγωγή στρώματος κειμένου με εναλλακτική λύση OCR για σαρωμένες σελίδες).
- Ο αναλυτής αναγνωρίζει 8 παθογόνα: HIV-1/2, σύφιλη, χλαμύδια, γονόρροια, HSV-1, HSV-2, ηπατίτιδα B, ηπατίτιδα C (μορφές αναφορών στα αγγλικά, ουκρανικά και ρωσικά).
- **Η κατάσταση μεμονωμένου παθογόνου δεν εμφανίζεται ποτέ σε άλλους χρήστες.** Τα προφίλ εμφανίζουν μόνο ένα ανώνυμο συμπέρασμα: **Safe / Compatible / Caution / Risk**.
- Οι εγγραφές επαλήθευσης DNA στο blockchain (`DNAVerification.sol`) τροφοδοτούν τις ροές ανάκτησης και επαλήθευσης.

### Προφίλ, Αναζήτηση & Επικοινωνία

- Φίλτρα αναζήτησης: «Τι αναζητάτε» (γνωριμίες / σύλληψη / πολυανδρική σύλληψη / STD τεστ), «Ποιον αναζητάτε» (άνδρες, γυναίκες, ζευγάρια), διαδοχικές επιλογές χώρα → πόλη, «μπορεί να ταξιδέψει στη χώρα σας» με λίστες ανά χώρα, χρώμα δέρματος, προτίμηση τεστ, μόνο συμβατά ως προς STD.
- Οδηγός εισαγωγής: ηλικία (με δυνατότητα απόκρυψης), γλώσσες, βιογραφικό, φωτογραφία.
- **Ιδιωτικότητα φωτογραφιών**: οι φωτογραφίες είναι θολές εκ προεπιλογής· ο ιδιοκτήτης παραχωρεί προβολές 15 δευτερολέπτων ή μόνιμες, με δική του πρωτοβουλία ή κατόπιν αιτήματος. Η προβολή είναι δωρεάν.
- **Συνομιλία P2P** μέσω libp2p (gossipsub) + Nostr, με εναλλακτική λύση HTTP API.

### Λειτουργίες Σύλληψης

- **Λειτουργία 2 — Pregnancy Bond**: μια γυναίκα δημιουργεί μια δεσμευτική σχέση, ένας άνδρας καταθέτει EVOLVE ως εγγύηση (≥ 100 στην τρέχουσα δοκιμαστική έκδοση), και οι δύο επιβεβαιώνουν· μετά από επιβεβαιωμένη εγκυμοσύνη και πατρότητα, η εγγύηση μεταφέρεται στη γυναίκα.
- **Λειτουργία 3 — Cryptic Choice**: μια γυναίκα ανοίγει μια συνεδρία 48 ωρών, οι άνδρες συμμετέχουν καταθέτοντας εγγύηση· εκείνη επιλέγει τον πατέρα — η δική του εγγύηση επιστρέφεται, ενώ το ποσό των υπολοίπων μοιράζεται: 90% σε εκείνη / 10% στον επιλεγμένο πατέρα.

### Εργαστήρια & Επαλήθευση

- **Ροή εργαστηριακών συνεργατών**: τα εργαστήρια εγγράφονται ως συνεργάτες, επαληθεύουν ασθενείς μέσω κωδικού QR και αντιστοίχισης προσώπου και επισυνάπτουν STD αναφορές (PDF/κείμενο με εξαγωγή OCR).
- **Companion Mode**: αυτοτελής ροή για την αξιολόγηση αποτελεσμάτων STD τεστ χωρίς εγγραφή στην πλατφόρμα γνωριμιών.
- **Safety Mode** (`VITE_PRODUCT_MODE=safety`): μια περιορισμένη δημόσια πρόσοψη (κατάσταση STD, δημόσιοι σύνδεσμοι προφίλ, έλεγχοι συμβατότητας) που συνεχίζει να λειτουργεί ακόμη κι αν οι λειτουργίες γνωριμιών/σύλληψης περιοριστούν σε κάποια δικαιοδοσία ή κατάστημα εφαρμογών.

### Token EVOLVE (μόνο δοκιμαστικό δίκτυο)

- ERC-20, μέγιστη προσφορά 8.000.000.000 EVOLVE, οι ενέργειες διαχειριστή περιορίζονται από ένα TimelockController 48 ωρών.
- **Οικονομία δώρων emoji**: ένα δώρο κοστίζει 1 EVOLVE, το οποίο κατανέμεται αναλογικά στους υφιστάμενους ιδιοκτήτες δώρων — ένα διαρκές μοντέλο εσόδων για τους κατόχους· τα δώρα είναι μεταβιβάσιμα.
- **EvolveFund**: κατάθεση εγγύησης από άνδρες (ελάχ. 15 EVOLVE, κλείδωμα 30 ημερών) που μετράει στο βάρος διακυβέρνησης· οι γυναίκες χρησιμοποιούν το υπόλοιπο του πορτοφολιού τους.
- **Ανταμοιβές επαλήθευσης**: 1 EVOLVE στον επαληθευμένο χρήστη και 1 EVOLVE στο επιβεβαιωμένο εργαστήριο κατά την επαλήθευση STD/DNA (συν ένα δοκιμαστικό faucet με περιορισμό συχνότητας).
- Το βάρος ψήφου διακυβέρνησης συνδυάζει αναδρομική φήμη (8 ψήφοι, βάθος 3), το μερίδιο παιδιών/πατρότητας, καθώς και δεσμευμένα ή διακρατούμενα EVOLVE.
- **LayerZero OFT** ενσωμάτωση για μελλοντικές πολυαλυσικές μεταφορές EVOLVE (οι εξαρτήσεις είναι έτοιμες· τίποτα δεν έχει αναπτυχθεί πέρα από το Sepolia ακόμη).

### Πλατφόρμα

- Εφαρμογή web (εγκαταστάσιμη ως PWA) και εφαρμογή κινητού σε Expo/React Native.
- Η διεπαφή έχει μεταφραστεί σε **34 γλώσσες**.
- Έτοιμη για πολλαπλά δίκτυα: 18 διαμορφώσεις δικτύων EVM (τα Arbitrum και Avalanche είναι τα προγραμματισμένα κύρια L2 — **δεν έχουν αναπτυχθεί ακόμη**).

## Αρχιτεκτονική & Τεχνολογικός Στοίβας

Monorepo που διαχειρίζεται με npm workspaces + Turborepo:

```
apps/
  web/          # Vite + React + TypeScript (κύρια εφαρμογή web, i18next, Prisma)
  mobile/       # Expo + React Native
packages/
  config/       # Feature flags & δυναμική απομακρυσμένη διαμόρφωση
  contracts/    # Solidity 0.8.24, Hardhat, Ignition, OpenZeppelin, LayerZero
  core/         # Κοινόχρηστοι τύποι, βοηθητικά εργαλεία, middleware, web3
  matching/     # Αλγόριθμοι ταιριάσματος, φίλτρα, κατάταξη
  p2p/          # δικτύωση libp2p (gossipsub) + Nostr
  storage/      # IPFS, Arweave, Lit Protocol
docs/           # Αρχιτεκτονική, tokenomics, οδικός χάρτης, FAQ
```

Βασικά έξυπνα συμβόλαια: `EVOLVE.sol` (ERC-20), `ProfileNFT.sol` (ERC-721), `TrustScore.sol`, `Voting.sol`, `Evolve2Earn.sol` (δώρα emoji + ανταμοιβές), `Governance.sol`, `BondManager.sol` (Λειτουργίες 2 & 3), `EvolveFund.sol`, `VerificationRegistry.sol`, `DNAVerification.sol`, ERC-4337 `SmartAccountFactory` + `Paymaster`, καθώς και ένα OpenZeppelin `TimelockController`.

Λεπτομέρειες: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) · [docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md) · [docs/TOKENOMICS.md](docs/TOKENOMICS.md) (στα αγγλικά).

## Οδικός Χάρτης

Σε εξέλιξη: ετοιμότητα παραγωγής της εφαρμογής web. Προγραμματισμένα: μητρώο εργαστηρίων on-chain και πιστοποίηση τεστ, πραγματικός προσαρμογέας παρόχου αλληλογραφίας για την εισαγωγή εργαστηριακών αναφορών, επαληθευμένες βεβαιώσεις on-chain στα προφίλ, ενημέρωση του token vesting για τις εκχωρήσεις ιδρυτή/προγραμματιστών, παροχή ρευστότητας DEX (επί του παρόντος μπλοκαρισμένη — απαιτεί αναπτύξεις του token σε mainnet). Η επέκταση σε πολλαπλά δίκτυα (Arbitrum, Avalanche και άλλες αλυσίδες EVM) ακολουθεί μετά την εδραίωση στο δοκιμαστικό δίκτυο.

Πλήρης λίστα: [docs/ROADMAP.md](docs/ROADMAP.md) (στα αγγλικά).

## Ξεκινώντας (για προγραμματιστές)

Απαιτήσεις: **Node.js 20+** και npm 10.x.

```bash
# Κλωνοποιήστε και εγκαταστήστε όλα τα workspaces
git clone https://github.com/Lilit-Moonlit/Evolve.git
cd Evolve
npm install

# Εφαρμογή web (διακομιστής ανάπτυξης Vite στο http://localhost:3000)
cd apps/web
npm run dev
npm test                # σουίτα vitest

# Έξυπνα συμβόλαια
cd packages/contracts
npm run compile         # hardhat compile
npm test                # σουίτα δοκιμών hardhat
npm run deploy:local    # ανάπτυξη όλων των συμβολαίων σε δίκτυο Hardhat in-process
```
