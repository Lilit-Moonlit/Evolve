# EVOLVE

**Γνωριμίες, σύλληψη και επαληθευμένη υγεία — ιδιωτικότητα εξ ορισμού, εμπιστοσύνη εκεί που μετράει.**

Η EVOLVE είναι μια αποκεντρωμένη πλατφόρμα ανοιχτού κώδικα για ανθρώπους που έχουν κουραστεί να παραδίδουν τον αριθμό τηλεφώνου τους, το πρόσωπό τους και τα πιο προσωπικά τους δεδομένα υγείας σε μια ξένη βάση δεδομένων. Συνδέεστε με το δικό σας πορτοφόλι κρυπτονομισμάτων — χωρίς τηλέφωνο, χωρίς email, χωρίς KYC — και μπορείτε να ανακτήσετε τον λογαριασμό σας μέσω μιας δέσμευσης DNA on-chain. Τα δεδομένα υγείας σας παραμένουν δικά σας: τα αποτελέσματα των τεστ επεξεργάζονται αυτόματα, οι επιμέρους καταστάσεις παθογόνων **δεν εμφανίζονται ποτέ** σε κανέναν, και το ταίριασμα βασίζεται μόνο σε ανώνυμα πορίσματα συμβατότητας (Safe / Compatible / Caution / Risk). Η συνομιλία λειτουργεί peer-to-peer μέσω libp2p και Nostr, με εναλλακτική λύση HTTP για ευκολία.

> **Κατάσταση — η πλατφόρμα λειτουργεί ήδη σήμερα· το mainnet και το DEX είναι τα επόμενα βήματα.**
> Γνωριμίες, σύλληψη, επαλήθευση υγείας, η ροή του εργαστηρίου, η συνομιλία P2P, το token EVOLVE και η διακυβέρνηση λειτουργούν όλα. Ακόμα προγραμματισμένα: μια **ανάπτυξη σε mainnet και ρευστότητα DEX**, καθώς και μια **σχεδιασμένη δημόσια πώληση** (βλ. [Το token EVOLVE](#το-token-evolve-μόνο-σε-testnet)).
> Τα έξυπνα συμβόλαια έχουν αναπτυχθεί **μόνο στο testnet Ethereum Sepolia**. Τίποτα εδώ δεν αποτελεί χρηματοοικονομική συμβουλή ή προσφορά επένδυσης.

> **Σας φάνηκε χρήσιμη η EVOLVE; Υποστηρίξτε την ανάπτυξη — κάθε δωρεά πηγαίνει σε κώδικα, εργαστηριακές συνεργασίες, φιλοξενία και μετάφραση → [DONATE.md](DONATE.md).**

## Τίποτα να φοβηθείτε

Η EVOLVE χτίστηκε γύρω από τις ερωτήσεις που κάνουν πραγματικά οι άνθρωποι πριν εμπιστευτούν μια τέτοια πλατφόρμα.

| Η ανησυχία                                          | Τι κάνει ήδη η EVOLVE γι' αυτό                                                                                                                                                                                                        |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| «Τα δεδομένα υγείας μου θα διαρρεύσουν.»            | Τα επιμέρους αποτελέσματα παθογόνων **δεν εμφανίζονται ποτέ** σε κανέναν — μόνο ένα ανώνυμο πόρισμα: Safe / Compatible / Caution / Risk.                                                                                              |
| «Οι φωτογραφίες μου θα καταλήξουν κάπου.»           | Οι φωτογραφίες είναι θολές εξ ορισμού. Ο κάτοχος παραχωρεί προβολή **15 δευτερολέπτων** ή **μόνιμη** — κατόπιν αιτήματος ή με δική του πρωτοβουλία. Η προβολή είναι δωρεάν.                                                           |
| «Θα πρέπει να παραδώσω ταυτότητα ή τηλέφωνο.»       | Σύνδεση με πορτοφόλι (SIWE). Χωρίς τηλέφωνο, χωρίς email, χωρίς KYC. Η ανάκτηση γίνεται μέσω δέσμευσης DNA on-chain.                                                                                                                  |
| «Αυτός ή εκείνη λέει ψέματα πως είναι υγιής.»       | Τα αποτελέσματα είναι **επαληθευμένα από εργαστήριο** (QR + ταύτιση προσώπου), και οι εξετάσεις του ζευγαριού γίνονται **στη συνάντηση** — μετράνε τα πρόσφατα αποτελέσματα STD, το DNA δεν γερνά.                                    |
| «Θα πάρει κάποιος τα λεφτά μου και θα εξαφανιστεί;» | Η σύλληψη βασίζεται σε ένα πραγματικό, επιρρεπές σε κίνδυνο στοίχημα: η κατάθεση ενός άνδρα μετακινείται μόνο όταν η πατρότητα **επιβεβαιωθεί**· διαφορετικά απλώς του επιστρέφεται.                                                  |
| «Είναι το token ένα pump-and-dump;»                 | Καμία πώληση δεν είναι ενεργή σήμερα· ο κώδικας είναι ανοιχτός (MIT)· το αποθεματικό εκτός κυκλοφορίας προορίζεται να κλειδωθεί σε ένα **θησαυροφυλάκιο που δεν μπορεί να αδειάσει**, από το οποίο ούτε ο ιδρυτής μπορεί να αποσύρει. |
| «Μπορεί η πλατφόρμα να κλείσει ή να απαγορευτεί;»   | Πρώτα μηνύματα peer-to-peer, αποκεντρωμένη αποθήκευση (IPFS / Arweave), 18 διαμορφώσεις δικτύων EVM και κανένα hardcoded domain.                                                                                                      |

## Τι & Γιατί

Οι παραδοσιακές εφαρμογές γνωριμιών σας ζητούν να ανταλλάξετε τον αριθμό τηλεφώνου, το email, τις φωτογραφίες και τις προσωπικές λεπτομέρειες υγείας με μια κεντρική βάση δεδομένων — και μετά να την εμπιστεύεστε για πάντα. Η EVOLVE ξεκινά από την αντίθετη προϋπόθεση: **ιδιωτικότητα εξ ορισμού, αυτοδιαχείριση (self-custody) και κανένα ενιαίο σημείο αποτυχίας**.

- **Ιδιωτικότητα εξ ορισμού** — τα δεδομένα υγείας δεν εκτίθενται ποτέ· μόνο ανώνυμα πορίσματα.
- **Ανθεκτικότητα σε απαγορεύσεις** — μηνύματα P2P πρώτα, αποκεντρωμένη αποθήκευση, σχεδιασμός πολλαπλών δικτύων, χωρίς hardcoded domains.
- **Ταυτότητα self-custody** — το πορτοφόλι σας είναι η σύνδεσή σας· ανάκτηση μέσω DNA αντί για email ή τηλέφωνο.
- **Κανένα KYC** — δεν απαιτείται ταυτότητα, τηλέφωνο ή email για τη χρήση της πλατφόρμας.

Διαβάστε την πλήρη αιτιολόγηση στο [docs/WHAT-AND-WHY.md](docs/WHAT-AND-WHY.md).

## Υγεία που μπορείτε πραγματικά να εμπιστευτείτε

- Ανεβάστε ένα τεστ STD ως ακατέργαστο κείμενο ή PDF (εξαγωγή στρώματος κειμένου, με εναλλακτική OCR για σκαναρίσματα).
- Ο parser γνωρίζει 8 παθογόνα: HIV-1/2, σύφιλη, χλαμύδια, γονόρροια, HSV-1, HSV-2, ηπατίτιδα Β, ηπατίτιδα C — σε αγγλική, ουκρανική και ρωσική μορφή αναφορών.
- **Η επιμέρους κατάσταση παθογόνων δεν εμφανίζεται ποτέ σε άλλους χρήστες.** Τα προφίλ δείχνουν μόνο το ανώνυμο πόρισμα: **Safe / Compatible / Caution / Risk**.
- Οι εγγραφές DNA on-chain (`DNAVerification.sol`) τροφοδοτούν την ανάκτηση και την επαλήθευση.

### Συνεργαζόμενα εργαστήρια — αποδείξεις, όχι υποσχέσεις

Μπείτε σε ένα συνεργαζόμενο εργαστήριο και δείξτε τον κωδικό QR σας. Το εργαστήριο τον σκανάρει, επιβεβαιώνει την ταυτότητά σας με **ταύτιση προσώπου** (ώστε κανείς άλλος να μην μπορεί να παραλάβει το αποτέλεσμά σας) και επισυνάπτει την αναφορά STD — PDF, σκανάρισμα ή κείμενο, ακόμα και με κακό OCR. Το αποτέλεσμα υπογράφεται από ένα πραγματικό εργαστήριο, όχι από εσάς, ώστε οι άλλοι βλέπουν ένα **επαληθευμένο γεγονός** αντί για τον λόγο σας. Και κάθε επιβεβαιωμένη επαλήθευση πληρώνει **1 EVOLVE στον ασθενή και 1 EVOLVE στο εργαστήριο** — και οι δύο πλευρές έχουν λόγο να είναι ειλικρινείς. Τα επιμέρους παθογόνα εξακολουθούν να μην εμφανίζονται ποτέ σε κανέναν.

## Βρίσκοντας κάποιον

- Φίλτρα αναζήτησης: «Τι ψάχνετε» (γνωριμίες / σύλληψη / πολυανδρική σύλληψη / τεστ STD), «Ποιον ψάχνετε» (άνδρες, γυναίκες, ζευγάρια), διαδοχικές επιλογές χώρα → πόλη, «μπορεί να ταξιδέψει στη χώρα σας» με λίστες ανά χώρα, χρώμα δέρματος, προτίμηση εξετάσεων, μόνο συμβατά ως προς STD.
- Οδηγός εισαγωγής: ηλικία (με δυνατότητα απόκρυψης), γλώσσες, βιογραφικό, φωτογραφία.
- **Συνομιλία P2P** μέσω libp2p (gossipsub) + Nostr, με εναλλακτικό HTTP API.

## Σύλληψη

Δύο τρόποι να σχεδιάσετε ένα παιδί — και οι δύο βασίζονται στην ίδια ιδέα: η πραγματική πρόθεση δείχνεται με ένα πραγματικό στοίχημα σε EVOLVE — ποτέ με υποσχέσεις. Η δέσμευση ενός άνδρα ζει στην κατάθεσή του στο EvolveFund (από 15 EVOLVE, κλειδωμένη για τουλάχιστον 30 ημέρες), και μια γυναίκα μπορεί να ορίσει τη δική της ελάχιστη κατάθεση για τους άνδρες που την προσεγγίζουν.

**Σύλληψη.** Η γυναίκα ηγείται: προσκαλεί έναν συγκεκριμένο άνδρα και τον ονομάζει σε ένα bond. Χρειάζεται ενεργή κατάθεση στο EvolveFund· όταν επιβεβαιώσουν και οι δύο, κλειδώνει και ξεκινά η αντίστροφη μέτρηση. Η εγκυμοσύνη δηλώνεται μεταξύ 14 και 30 ημερών μετά την επιβεβαίωση, και τα τεστ STD και DNA του ζευγαριού γίνονται στην ίδια τη συνάντηση — μετράνε τα πρόσφατα αποτελέσματα STD, το DNA δεν γερνά. Μόλις επιβεβαιωθεί η πατρότητα, η κατάθεση του άνδρα περνά στη γυναίκα· αν δεν επιβεβαιωθεί, η κατάθεση απλώς του επιστρέφεται. Τίποτα δεν αλλάζει χέρια μέχρι να διευκρινιστούν τα γεγονότα.

**Πολυανδρική σύλληψη.** Η επιλογή ανήκει σε εκείνη — και μένει ιδιωτική. Ανοίγει μια συνεδρία που διαρκεί 48 ώρες — χωρίς δική της κατάθεση (μπορεί να προσθέσει μία μόνο για τη φήμη, αν το επιθυμεί). Άνδρες με ενεργή κατάθεση μπορούν να συμμετάσχουν — έως 50 — και να επιβεβαιώσουν, κάτι που κλειδώνει το στοίχημά τους. Δεκατέσσερις ημέρες μετά το κλείσιμο της συνεδρίας, επιλέγεται ο πατέρας. Παίρνει την κατάθεσή του πίσω συν μια ανταμοιβή από το κοινό: διπλάσια της κατάθεσής του και 1 EVOLVE για κάθε άλλον συμμετέχοντα. Οι άνδρες που δεν επιλέγονται χάνουν το στοίχημά τους — 90% στη γυναίκα, 10% στον επιλεγμένο πατέρα. Εκείνη δεν ρισκάρει τίποτα και μπορεί μόνο να κερδίσει· οι άνδρες βάζουν το στοίχημά τους πίσω από το δικαίωμα να επιλεγούν.

## Το token EVOLVE (μόνο σε testnet)

- ERC-20, μέγιστο απόθεμα **8,000,000,000 EVOLVE**. Οι ενέργειες διαχειριστή περιορίζονται από ένα `TimelockController` 48 ωρών.
- **Προγραμματισμένη κατανομή αποθέματος** — σχεδιασμένη ώστε σχεδόν όλο το απόθεμα να δουλεύει για τους χρήστες, όχι για τους γνωστούς του συστήματος:

| Σκοπός                                                      |        EVOLVE |
| ----------------------------------------------------------- | ------------: |
| Ιδρυτές και ομάδα (μισθός / ανταμοιβή)                      |    25,000,000 |
| Απόθεμα DEX (μελλοντικό)                                    |     4,000,000 |
| Δημόσια πώληση (προγραμματισμένη)                           |     5,000,000 |
| Απόθεμα ανταμοιβών — εργαστήρια, ασθενείς, μητέρες, πατέρες | 7,966,000,000 |

- **Προγραμματισμένη δημόσια πώληση** — 5,000,000 EVOLVE προς πώληση από την εφαρμογή στα **$0.8 το καθένα**, πληρωτέα σε οποιοδήποτε token υποστηρίζει η εφαρμογή· τα έσοδα χρηματοδοτούν την ανάπτυξη. _(Προγραμματισμένο — δεν είναι ενεργό ακόμα.)_
- **Εκπομπή χωρίς εμπιστοσύνη (προγραμματισμένη)** — το απόθεμα ανταμοιβών ~7,966,000,000 πρόκειται να κλειδωθεί σε ένα `RewardVault` που δεν μπορεί να αδειάσει: απελευθερώνεται μόνο σταδιακά μέσω ανταμοιβών εργαστηρίων, ασθενών, μητέρων και πατέρων, ενώ οι αλλαγές κανόνων απαιτούν ψηφοφορία διακυβέρνησης. Ούτε ο ιδρυτής μπορεί να αποσύρει από αυτό. Σχέδιο: [docs/REWARD-VAULT-PLAN.md](docs/REWARD-VAULT-PLAN.md).
- **Οικονομία δώρων emoji** — ένα δώρο κοστίζει 1 EVOLVE, κατανεμημένο αναλογικά στους υπάρχοντες κατόχους δώρων· ένα διαρκές μοντέλο εσόδων, και τα δώρα μεταφέρονται.
- **EvolveFund** — staking ανδρών (ελάχ. 15 EVOLVE, κλείδωμα 30 ημερών) που μετράει στο βάρος διακυβέρνησης· οι γυναίκες χρησιμοποιούν το υπόλοιπο του πορτοφολιού τους.
- **Ανταμοιβές επαλήθευσης** — 1 EVOLVE στον επαληθευμένο χρήστη και 1 EVOLVE στο εργαστήριο που επιβεβαιώνει ανά επαλήθευση STD/DNA (συν ένα faucet με όριο συχνότητας).
- **Διακυβέρνηση** — το βάρος ψήφου συνδυάζει αναδρομική φήμη (8 ψήφοι, βάθος 3), μερίδιο παιδιών/πατρότητας και EVOLVE σε staking ή σε κατοχή.
- **LayerZero OFT** ενσωμάτωση για μελλοντικές μεταφορές EVOLVE πολλαπλών αλυσίδων (εξαρτήσεις σε θέση· τίποτα δεν έχει αναπτυχθεί πέρα από το Sepolia).

## Υποστηρίξτε το έργο

Η EVOLVE είναι ανεξάρτητη και ανοιχτού κώδικα. Αν σας είναι χρήσιμη, μπορείτε να υποστηρίξετε την ανάπτυξη με μια δωρεά — κάθε συνεισφορά πηγαίνει σε κώδικα, εργαστηριακές συνεργασίες, φιλοξενία και μετάφραση.

- **Λεπτομέρειες δωρεών (EVM, Monero και άλλα):** [DONATE.md](DONATE.md)
- **Πολύγλωσση σελίδα δωρεών (34 γλώσσες):** **https://lilit-moonlit.github.io/Evolve/** · **https://limitafternoon.codeberg.page/Evolve/**

Μια δημόσια πώληση token είναι στο roadmap, αλλά **δεν** είναι ενεργή σήμερα. Οι δωρεές είναι δώρα που υποστηρίζουν την ανάπτυξη ανοιχτού κώδικα και δεν δίνουν κανένα δικαίωμα σε tokens, μερίδια, αποδόσεις ή κέρδη. Παρακαλούμε δώστε μόνο όσα μπορείτε να αντέξετε να χάσετε.

## Αρχιτεκτονική & Τεχνολογίες

Monorepo που διαχειρίζεται με npm workspaces + Turborepo:

```
apps/
  web/          # Vite + React + TypeScript (main web app, i18next, Prisma)
  mobile/       # Expo + React Native
packages/
  config/       # Feature flags & dynamic remote configuration
  contracts/    # Solidity 0.8.24, Hardhat, Ignition, OpenZeppelin, LayerZero
  core/         # Shared types, utilities, middleware, web3
  matching/     # Matching algorithms, filters, ranking
  p2p/          # libp2p (gossipsub) + Nostr networking
  storage/      # IPFS, Arweave, Lit Protocol
docs/           # Architecture, tokenomics, roadmap, FAQ
```

Βασικά έξυπνα συμβόλαια: `EVOLVE.sol` (ERC-20), `ProfileNFT.sol` (ERC-721), `TrustScore.sol`, `Voting.sol`, `Evolve2Earn.sol` (δώρα emoji + ανταμοιβές), `Governance.sol`, `BondManager.sol` (σύλληψη και πολυανδρική σύλληψη), `EvolveFund.sol`, `VerificationRegistry.sol`, `DNAVerification.sol`, ERC-4337 `SmartAccountFactory` + `Paymaster`, καθώς και ένα `TimelockController` του OpenZeppelin.

Λεπτομέρειες: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) · [docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md) · [docs/TOKENOMICS.md](docs/TOKENOMICS.md)

## Ξεκινώντας (προγραμματιστές)

Απαιτήσεις: **Node.js 20+** και npm 10.x.

```bash
# Clone and install all workspaces
git clone https://github.com/Lilit-Moonlit/Evolve.git
cd Evolve
npm install

# Web app (Vite dev server on http://localhost:3000)
cd apps/web
npm run dev
npm test                # vitest suite

# Smart contracts
cd packages/contracts
npm run compile         # hardhat compile
npm test                # hardhat test suite
npm run deploy:local    # deploy all contracts to an in-process Hardhat network
```
