Додав нового агента: **Aider** (локальний, через Ollama).

### Хто це

Aider + Ollama = локальний coding assistant. Працює оффлайн, без API ключів, без інтернету. Модель: deepseek-coder-v2:16b.

### Коли використовувати

- Ти offline / недоступний → Aider підхоплює твою задачу
- Проста правка (імпорт, конфіг) → Aider швидше
- Немає інтернету → Aider працює локально

### Як запустити

```powershell
# З задачею
.\.agent-chat\scripts\aider-run.ps1 -Task "Add polygon chain" -Files "apps/web/src/App.tsx"

# З моделлю
.\.agent-chat\scripts\aider-run.ps1 -Model "deepseek-coder-v2:16b"
```

### Правила

- Aider не блокує файли (локальний агент)
- Пиши `to: all` якщо хочеш щоб Aider підхопив задачу
- Aider теж може писати в чат через статусні файли
- Промпт в `.agent-chat/prompts/aider.md`
