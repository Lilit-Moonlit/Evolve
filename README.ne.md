# EVOLVE

**डेटिङ, गर्भधारण र प्रमाणित स्वास्थ्य — पूर्वनिर्धारित रूपमा निजी, जहाँ साँचो विश्वास चाहिन्छ त्यहीँ भरपर्दो।**

EVOLVE त्यस्ता मानिसहरूका लागि खुला-स्रोत, विकेन्द्रीकृत प्लेटफर्म हो जो आफ्नो फोन नम्बर, आफ्नो अनुहार र आफ्नो सबैभन्दा निजी स्वास्थ्य तथ्याङ्क अरूको डाटाबेसमा बुझाइरहन चाहन्नन्। तपाईं आफ्नै क्रिप्टो वालेटबाट लगइन गर्नुहुन्छ — फोन छैन, इमेल छैन, KYC छैन — र अन-चेन DNA प्रतिबद्धता मार्फत आफ्नो खाता फिर्ता लिन सक्नुहुन्छ। तपाईंको स्वास्थ्य तथ्याङ्क तपाईंकै रहन्छ: परीक्षण नतिजाहरू स्वचालित रूपमा पार्स हुन्छन्, व्यक्तिगत रोगजनक (pathogen) को अवस्था कसैलाई पनि **कहिल्यै** देखाइँदैन, र म्याचिङले गुमनाम अनुकूलता निर्णयमा मात्र भर पर्छ (Safe / Compatible / Caution / Risk)। च्याट libp2p र Nostr मार्फत पिअर-टु-पियर चल्छ, सुविधाका लागि HTTP फलब्याकसहित। उपहार र स्थानान्तरणहरू पूर्ण गोप्यतातर्फ अघि बढ्दै छन्: प्रेषक-निजी उपहारहरू आजैदेखि उपलब्ध छन्, र रोडम्यापमा Railgun शिल्डेड वालेट र Aztec शून्य-ज्ञान प्रोटोटाइप छन् ([गोपनीयता र गोप्य लेनदेन](#privacy--confidential-transactions) हेर्नुहोस्)।

> **स्थिति — डेमो मोड, सक्रिय रूपमा विकासोन्मुख।**
> डेटिङ, गर्भधारण, स्वास्थ्य प्रमाणीकरण, प्रयोगशाला कार्यप्रवाह, P2P च्याट, EVOLVE टोकन र गभर्नेन्स — सबै कार्यान्वयन भइसकेका छन् र एउटा **स्थानीय डेमो** मा चल्छन् — एप भने **अझै सार्वजनिक रूपमा परिनियोजित भएको छैन**। अझै बाँकी: **मेननेट परिनियोजन र DEX लिक्विडिटी**, साथै एउटा **योजनाबद्ध सार्वजनिक बिक्री** ([EVOLVE टोकन](#the-evolve-token-testnet-only) हेर्नुहोस्)।

## के र किन

परम्परागत डेटिङ एपहरूले तपाईंको फोन नम्बर, इमेल, फोटो र निजी स्वास्थ्य विवरणहरू एउटा केन्द्रीय डाटाबेससँग साट्न भन्छन् — र त्यसपछि त्यही डाटाबेसलाई सधैँभरि विश्वास गर्न। EVOLVE उल्टो आधारबाट सुरु हुन्छ: **पूर्वनिर्धारित रूपमा गोपनीयता, आत्म-अभिरक्षण (self-custody), र एकल विफलता बिन्दु नहुनु**।

- **पूर्वनिर्धारित रूपमा गोपनीयता** — स्वास्थ्य तथ्याङ्क कहिल्यै खुलासने छैन; केवल गुमनाम निर्णयहरू।
- **प्रतिबन्ध प्रतिरोध** — P2P-प्रथम सन्देश, विकेन्द्रीकृत भण्डारण, बहु-नेटवर्क डिजाइन, कुनै हार्डकोडेड डोमेन छैन।
- **आत्म-अभिरक्षित पहिचान** — तपाईंको वालेट नै तपाईंको लगइन हो; इमेल वा फोनको सट्टा DNA-आधारित पुनर्प्राप्ति।
- **KYC ढोका छैन** — प्लेटफर्म प्रयोग गर्न सरकारी परिचयपत्र, फोन वा इमेल आवश्यक पर्दैन।

पूर्ण तर्क [docs/WHAT-AND-WHY.md](docs/WHAT-AND-WHY.md) मा पढ्नुहोस्।

## साँच्चै भरपर्ने स्वास्थ्य

- STD परीक्षण कच्चा पाठ वा PDF का रूपमा अपलोड गर्नुहोस् (पाठ-तह निकासी, स्क्यानका लागि OCR फलब्याकसहित)।
- पार्सरले 8 वटा रोगजनक चिन्छ: HIV-1/2, Syphilis, Chlamydia, Gonorrhea, HSV-1, HSV-2, Hepatitis B, Hepatitis C — अंग्रेजी, युक्रेनी र रूसी रिपोर्ट ढाँचाहरूमा।
- **व्यक्तिगत रोगजनकको अवस्था अन्य प्रयोगकर्ताहरूलाई कहिल्यै देखाइँदैन।** प्रोफाइलहरूले केवल गुमनाम निर्णय देखाउँछन्: **Safe / Compatible / Caution / Risk**।
- अन-चेन DNA रेकर्डहरू (`DNAVerification.sol`) ले पुनर्प्राप्ति र प्रमाणीकरणलाई सञ्चालन गर्छन्।

### साझेदार प्रयोगशालाहरू — प्रमाण, वाचन होइन

साझेदार प्रयोगशालामा पस्नुहोस् र आफ्नो QR कोड देखाउनुहोस्। प्रयोगशालाले यो स्क्यान गर्छ, **अनुहार मिलान** द्वारा तपाईंको पहिचान पुष्टि गर्छ (ताकि अरू कोही पनि तपाईंको नतिजा लिन सक्दैन) र STD रिपोर्ट संलग्न गर्छ — PDF, स्क्यान वा पाठ, खराब OCR भए पनि। नतिजामा तपाईंले होइन, वास्तविक प्रयोगशालाले हस्ताक्षर गर्छ, त्यसैले अरूले तपाईंको शब्दको सट्टा एउटा **प्रमाणित तथ्य** देख्छन्। र प्रत्येक पुष्टि गरिएको प्रमाणीकरणले **बिरामीलाई 1 EVOLVE र प्रयोगशालालाई 1 EVOLVE** तिर्छ — दुवै पक्षसँग इमानदार हुनुको आफ्नै कारण हुन्छ। व्यक्तिगत रोगजनकहरू भने अझै पनि कसैलाई देखाइँदैन।

## कसैलाई खोज्दै

- खोज फिल्टरहरू: "तपाईं के खोज्दै हुनुहुन्छ" (डेटिङ / गर्भधारण / बहुपति गर्भधारण / STD परीक्षण), "तपाईं कसलाई खोज्दै हुनुहुन्छ" (पुरुष, महिला, जोडीहरू), क्यास्केडिङ देश → सहर चयनहरू, देश-अनुसार सूचीसहित "तपाईंको देशमा आउन सक्छन्", छालाको रङ, परीक्षण प्राथमिकता, केवल STD-अनुकूल।
- अनबोर्डिङ विजार्ड: उमेर (लुकाउन सकिने), भाषाहरू, परिचय (बायो), फोटो।
- libp2p (gossipsub) + Nostr मार्फत **P2P च्याट**, HTTP API फलब्याकसहित।

## गर्भधारण

बच्चा योजना बनाउन दुई तरिका छन्, र दुवै एउटै विचारमा आधारित छन्: वास्तविक निश्चय EVOLVE मा वास्तविक स्टेकले देखाइन्छ — वाचनले कहिल्यै होइन। पुरुषको प्रतिबद्धता उसको EvolveFund निक्षेपमा बस्छ (15 EVOLVE देखि, कम्तीमा 30 दिन थुनिएको), र महिलाले आफूसम्म पुग्ने पुरुषहरूका लागि आफ्नै न्यूनतम निक्षेप तोक्न सक्छिन्।

**गर्भधारण।** महिलाको नेतृत्व हुन्छ: उनले एउटा निश्चित पुरुषलाई निमन्त्रणा दिन्छिन् र उसलाई एउटा बन्डमा नामाङ्कित गर्छिन्। उसलाई सक्रिय EvolveFund निक्षेप चाहिन्छ; दुवैले पुष्टि गरेपछि, यो थुनिन्छ र काउन्टडाउन सुरु हुन्छ। गर्भावस्था पुष्टिपछि 14 देखि 30 दिनभित्र रिपोर्ट गरिन्छ, र जोडीका STD र DNA परीक्षणहरू भेटैको बखत लिइन्छन् — हालका STD नतिजाले महत्त्व राख्छ, DNA पुरानो हुँदैन। पितृत्व पुष्टि भएपछि, पुरुषको निक्षेप महिलालाई जान्छ; पुष्टि नभएमा, निक्षेप सरल रूपमा उसैलाई फिर्ता छाडिन्छ। तथ्यहरू निश्चित नभएसम्म केही पनि हातबाट हातमा सर्दैन।

**बहुपति गर्भधारण।** छनोट उनकै हो, र निजी नै रहन्छ। उनले 48 घण्टा चल्ने एउटा सत्र खोल्छिन् — आफ्नै कुनै निक्षेप बिना (उनी चाहे त, प्रतिष्ठाका लागि मात्र थप्न सक्छिन्)। सक्रिय निक्षेप भएका पुरुषहरू सामेल हुन सक्छन् — 50 सम्म — र पुष्टि गर्छन्, जसले उनीहरूको स्टेक थुन्छ। सत्र बन्द भएको चौध दिनपछि, बाबु छानिन्छ। उसले आफ्नो निक्षेप फिर्ता पाउँछ, साथै पूलबाट पुरस्कार: आफ्नो निक्षेपको दोब्बर र अन्य प्रत्येक सहभागीका लागि 1 EVOLVE। नछानिएका पुरुषहरूले आफ्नो स्टेक गुमाउँछन् — 90% महिलालाई, 10% छानिएका बाबुलाई। उनलाई कुनै जोखिम छैन, प्राप्त गर्न मात्र सक्छिन्; पुरुषहरूले भने छानिने अधिकारको पछाडि आफ्नो स्टेक लगाउँछन्।

गोपनीयता पूर्वनिर्धारित हो — र EVOLVE पूर्ण गोप्य अन-चेन स्थानान्तरणतर्फको रोडम्याप बनाइरहेको छ।

- **निजी उपहार** — एउटा गुलाब 🌹 वा क्याक्टस 🌵 (1 EVOLVE) पठाउनुहोस् र यो तपाईंले पठाउनुभयो भनी कसले देख्न सक्छ छान्नुहोस्: _सार्वजनिक_, _प्राप्तकर्ता बाहेक सबैलाई गुमनाम_, वा _पूर्ण रूपमा गुमनाम_। गुमनाम मोडहरूमा उपहार एकल-प्रयोग भाउचरका रूपमा यात्रा गर्छ, जसलाई प्राप्तकर्ताले आफ्नै वालेटबाट दाबी गर्छ, त्यसैले प्रेषक कहिल्यै अन-चेनमा देखा पर्दैन। (आजको प्रेषक गुमनामता सामान्य-स्तरको हो: फन्डिङ लेनदेनलाई समय र रकमका आधारमा सम्बन्धित गर्न सकिन्छ।)
- **Railgun शिल्डेड वालेट** — फिचर-फ्ल्याग गरिएको निजी वालेट (`VITE_RAILGUN_ENABLED`, पूर्वनिर्धारित रूपमा बन्द) जसले Railgun को लाइभ शून्य-ज्ञान पूल प्रयोग गरेर रकम र ठेगानाहरू लुकाउँछ। यो नै साँचो प्रेषक गुमनामताको बाटो हो।
- **Aztec प्रोटोटाइप** — उही निजी-स्थानान्तरण र निजी-बन्ड तर्क, शून्य-ज्ञान Noir सर्किटहरूका रूपमा व्यक्त गरिएको, र Aztec उत्पादन-तयार नभएसम्म एउटा स्पष्ट ढोकापछाडि राखिएको। [docs/AZTEC-PROTOTYPE.md](docs/AZTEC-PROTOTYPE.md) हेर्नुहोस्।
- **दुई-वालेट मोडेल** — एउटा सार्वजनिक स्टेक-वालेट गभर्नेन्समा भाग लिन्छ; निजी शिल्डेड वालेटलाई भने जानाजानी गभर्नेन्स भारबाट **बहिष्कृत** गरिएको छ, जसले गोपनीयता र मतदान शक्तिलाई छुट्टाछुट्टै राख्छ।

## आर्किटेक्चर र प्राविधिक स्ट्याक

npm workspaces + Turborepo सँग व्यवस्थापित मोनोरिपो:

```
apps/
  web/          # Vite + React + TypeScript (main web app, i18next, Prisma)
  mobile/       # Expo + React Native
packages/
  config/       # Feature flags & dynamic remote configuration
  contracts/    # Solidity 0.8.24, Hardhat, Ignition, OpenZeppelin, LayerZero
  core/         # Shared types, utilities, middleware, web3
  matching/     # Matching algorithms, filters, ranking
  p2p/          # libp2p (gossipsub) + Nostr networking
  storage/      # IPFS, Arweave, Lit Protocol
docs/           # Architecture, tokenomics, roadmap, FAQ
```

मुख्य स्मार्ट कन्ट्र्याक्टहरू: `EVOLVE.sol` (ERC-20), `ProfileNFT.sol` (ERC-721), `TrustScore.sol`, `Voting.sol`, `Evolve2Earn.sol` (इमोजी उपहार + पुरस्कार), `Governance.sol`, `BondManager.sol` (गर्भधारण र बहुपति गर्भधारण), `EvolveFund.sol`, `VerificationRegistry.sol`, `DNAVerification.sol`, ERC-4337 `SmartAccountFactory` + `Paymaster`, र एउटा OpenZeppelin `TimelockController`।

## रोडम्याप

पूरै सूची: [docs/ROADMAP.md](docs/ROADMAP.md)।

## सुरु गर्ने तरिका (विकासकर्ताहरूका लागि)

आवश्यकताहरू: **Node.js 20+** र npm 10.x।

```bash
# Clone and install all workspaces
git clone https://github.com/Lilit-Moonlit/Evolve.git
cd Evolve
npm install

# Web app (Vite dev server on http://localhost:3000)
cd apps/web
npm run dev
npm test                # vitest suite

# Smart contracts
cd packages/contracts
npm run compile         # hardhat compile
npm test                # hardhat test suite
npm run deploy:local    # deploy all contracts to an in-process Hardhat network
```
