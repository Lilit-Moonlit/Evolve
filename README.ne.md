# EVOLVE

**डेटिङ, गर्भधारण र प्रमाणित स्वास्थ्य — पूर्वनिर्धारित रूपमा निजी, जहाँ जरूरी छ त्यहीँ भरपर्दो।**

EVOLVE त्यस्ता मानिसहरूका लागि खुला स्रोत, विकेन्द्रीकृत प्लेटफर्म हो जो आफ्नो फोन नम्बर, आफ्नो अनुहार र आफ्नो सबैभन्दा निजी स्वास्थ्य विवरण अरूको डाटाबेसमा बुझाउन थालिसकेका छन्। तपाईं आफ्नै क्रिप्टो वालेटले लगइन गर्नुहुन्छ — फोन छैन, इमेल छैन, KYC छैन — र अन-चेन DNA प्रतिबद्धताबाट आफ्नो खाता फिर्ता पाउन सक्नुहुन्छ। तपाईंको स्वास्थ्य विवरण तपाईंैको रहन्छ: परीक्षण नतिजाहरू स्वतः पदवर्णन (parse) हुन्छन्, व्यक्तिगत रोगजनकको अवस्था कसैलाई पनि **कहिल्यै** देखाइँदैन, र म्याचिङ गुमनाम अनुकूलता निर्णयमा मात्र भर पर्छ (Safe / Compatible / Caution / Risk)। च्याट libp2p र Nostr मार्फत पियर-टु-पियर चल्छ, सुविधाका लागि HTTP फलब्याकसहित।

> **स्थिति — प्लेटफर्म आजैदेखि काम गर्छ; मेननेट र DEX अर्को चरण हुन्।**

## के र किन

परम्परागत डेटिङ एपहरू तपाईंको फोन नम्बर, इमेल, फोटो र निजी स्वास्थ्य विवरण केन्द्रीय डाटाबेससँग साट्न आग्रह गर्छन् — र त्यसपछि त्यही डाटाबेसमा सधैँ भरोसा गर्न भन्छन्। EVOLVE उल्टो आधारबाट सुरु हुन्छ: **पूर्वनिर्धारित निजीता, आत्म-अभिरक्षा, र एकल विफलता बिन्दु नहुनु**।

- **पूर्वनिर्धारित निजीता** — स्वास्थ्य विवरण कहिल्यै खुलासा हुँदैन; केवल गुमनाम निर्णय।
- **प्रतिबन्ध प्रतिरोध** — पहिले P2P सन्देश, विकेन्द्रीकृत भण्डारण, बहु-नेटवर्क डिजाइन, हार्डकोडेड डोमेन छैन।
- **आत्म-अभिरक्षित पहिचान** — तपाईंको वालेट नै तपाईंको लगइन हो; इमेल वा फोनको सट्टा DNA-आधारित पुनर्प्राप्ति।
- **KYC ढोका छैन** — प्लेटफर्म प्रयोग गर्न सरकारी परिचयपत्र, फोन वा इमेल आवश्यक छैन।

पूर्ण तर्क [docs/WHAT-AND-WHY.md](docs/WHAT-AND-WHY.md) मा पढ्नुहोस्।

## साँच्चै भरपर्दो स्वास्थ्य

- STD परीक्षण कच्चा पाठ वा PDF का रूपमा अपलोड गर्नुहोस् (टेक्स्ट-तह निकासी, स्क्यानका लागि OCR फलब्याकसहित)।
- पार्सरले 8 वटा रोगजनक चिन्छ: HIV-1/2, Syphilis, Chlamydia, Gonorrhea, HSV-1, HSV-2, Hepatitis B, Hepatitis C — अंग्रेजी, युक्रेनियन र रूसी रिपोर्ट ढाँचामा।
- **व्यक्तिगत रोगजनक अवस्था अन्य प्रयोगकर्तालाई कहिल्यै देखाइँदैन।** प्रोफाइलले केवल गुमनाम निर्णय देखाउँछ: **Safe / Compatible / Caution / Risk**।
- अन-चेन DNA रेकर्डहरू (`DNAVerification.sol`) ले पुनर्प्राप्ति र प्रमाणीकरण चलाउँछन्।

### साझेदार प्रयोगशालाहरू — प्रतिज्ञा होइन, प्रमाण

साझेदार प्रयोगशालामा पसेर आफ्नो QR कोड देखाउनुहोस्। प्रयोगशालाले त्यो स्क्यान गर्छ, **अनुहार मिलान**ले तपाईंको पहिचान पुष्टि गर्छ (अरू कसैले तपाईंको नतिजा लिन नसकोस्) र STD रिपोर्ट संलग्न गर्छ — PDF, स्क्यान वा पाठ, खराब OCR भए पनि। नतिजा तपाईंले होइन, साँचो प्रयोगशालाले हस्ताक्षर गर्छ, त्यसैले अरूले तपाईंको शब्दको सट्टा **प्रमाणित तथ्य** देख्छन्। र हरेक पुष्टि गरिएको प्रमाणीकरणले **बिरामीलाई 1 EVOLVE र प्रयोगशालालाई 1 EVOLVE** तिर्छ — दुवै पक्षसँग इमानदार हुने कारण हुन्छ। व्यक्तिगत रोगजनक भने अझै पनि कसैलाई देखाइँदैन।

## कसैलाई भेट्टाउने

- खोज फिल्टरहरू: "तपाईं के खोज्दैहुनुहुन्छ" (डेटिङ / गर्भधारण / बहुपति गर्भधारण / STD परीक्षण), "कसलाई खोज्दैहुनुहुन्छ" (पुरुष, महिला, जोडी), क्रमिक देश → सहर छनोट, देश-अनुसार सूचीसहित "तपाईंको देश आउन सक्छु", छालाको रङ, परीक्षण अभिरुचि, केवल STD-अनुकूल।
- अनबोर्डिङ विजार्ड: उमेर (लुकाउन मिल्ने), भाषाहरू, बायो, फोटो।
- libp2p (gossipsub) + Nostr मार्फत **P2P च्याट**, HTTP API फलब्याकसहित।

## गर्भधारण

बच्चा योजना गर्ने दुई बाटो छन्, र दुवै एउटै विचारमा टेक्छन्: साँचो अभिप्राय EVOLVEमा साँचो स्टेकले देखिन्छ — कहिल्यै वाचाबाट होइन। पुरुषको प्रतिबद्धता उसको EvolveFund निक्षेपमा बस्छ (15 EVOLVEदेखि, कम्तीमा 30 दिन थुनिएको), र महिलाले आफूसम्म पुग्ने पुरुषहरूका लागि आफ्नै न्यूनतम निक्षेप तोक्न सक्छिन्।

**गर्भधारण।** महिला नेतृत्व लिन्छिन्: उनले कुनै विशेष पुरुषलाई निमन्त्रणा दिन्छिन् र बन्डमा उसको नाम राख्छिन्। उसलाई सक्रिय EvolveFund निक्षेप चाहिन्छ; दुवैले पुष्टि गरेपछि त्यो थुनिन्छ र काउन्टडाउन सुरु हुन्छ। पुष्टिपछि 14 देखि 30 दिनभित्र गर्भावस्था रिपोर्ट गरिन्छ, र जोडीका STD तथा DNA परीक्षण भेटैको बखत लिइन्छन् — ताजा STD नतिजाले अर्थ राख्छ, DNA बूढो हुँदैन। पितृत्व पुष्टि भएपछि पुरुषको निक्षेप महिलालाई जान्छ; पुष्टि नभए निक्षेप उसैलाई फिर्ता छाडिन्छ। तथ्य नमिलिसम्म केही हातफेर हुँदैन।

**बहुपति गर्भधारण।** छनोट उनको हो, र निजी नै रहन्छ। उनले 48 घण्टा चल्ने सत्र खोल्छिन् — आफ्नै निक्षेपबिना (चाहे इज्जतका लागि मात्र थप्न सक्छिन्)। सक्रिय निक्षेप भएका पुरुषहरू सामेल हुन सक्छन् — 50 सम्म — र पुष्टि गर्छन्, जसले उनीहरूको स्टेक थुन्छ। सत्र बन्द भएको चौध दिनपछि बाबु छानिन्छ। उसले आफ्नो निक्षेप फिर्ता पाउँछ, साथै पुलबाट पुरस्कार: आफ्नो निक्षेपको दोब्बर र अन्य हरेक सहभागीका लागि 1 EVOLVE। नछानिएका पुरुषहरूले स्टेक गुमाउँछन् — 90% महिलालाई, 10% छानिएका बाबुलाई। उनले केही जोखिम लिँदैनन्, जित्न मात्र सक्छिन्; पुरुषहरूले छानिने अधिकारको पछाडि आफ्नो स्टेक लगाउँछन्।

- **EvolveFund** — पुरुष स्टेकिङ (न्यूनतम 15 EVOLVE, 30-दिन थुनाइ) जुन गभर्नेन्स वजनमा गनिन्छ; महिलाहरूले वालेट ब्यालान्स प्रयोग गर्छन्।
- **प्रमाणीकरण पुरस्कार** — प्रत्येक STD/DNA प्रमाणीकरणमा प्रमाणित प्रयोगकर्तालाई 1 EVOLVE र पुष्टि गर्ने प्रयोगशालालाई 1 EVOLVE (थप दर-सीमित फसेट)।
- **गभर्नेन्स** — मतको वजनमा पुनरावर्ती प्रतिष्ठा (8 मत, गहिराइ 3), सन्तान/पितृत्व हिस्सा, र स्टेक गरिएको वा राखिएको EVOLVE मिसिन्छ।
- भविष्यका बहु-चेन EVOLVE स्थानान्तरणका लागि **LayerZero OFT** एकीकरण (निर्भरता तयार; Sepolia बाहेक अझै केही परिनियोजित छैन)।

## आर्किटेक्चर र प्रविधि स्ट्याक

npm workspaces + Turborepo ले व्यवस्थापित मोनोरेपो:

```
apps/
  web/          # Vite + React + TypeScript (main web app, i18next, Prisma)
  mobile/       # Expo + React Native
packages/
  config/       # Feature flags & dynamic remote configuration
  contracts/    # Solidity 0.8.24, Hardhat, Ignition, OpenZeppelin, LayerZero
  core/         # Shared types, utilities, middleware, web3
  matching/     # Matching algorithms, filters, ranking
  p2p/          # libp2p (gossipsub) + Nostr networking
  storage/      # IPFS, Arweave, Lit Protocol
docs/           # Architecture, tokenomics, roadmap, FAQ
```

मुख्य स्मार्ट कन्ट्र्याक्टहरू: `EVOLVE.sol` (ERC-20), `ProfileNFT.sol` (ERC-721), `TrustScore.sol`, `Voting.sol`, `Evolve2Earn.sol` (इमोजी उपहार + पुरस्कार), `Governance.sol`, `BondManager.sol` (गर्भधारण र बहुपति गर्भधारण), `EvolveFund.sol`, `VerificationRegistry.sol`, `DNAVerification.sol`, ERC-4337 `SmartAccountFactory` + `Paymaster`, र OpenZeppelin `TimelockController`।

विवरण: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) · [docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md) · [docs/TOKENOMICS.md](docs/TOKENOMICS.md)

## रोडम्याप

प्रगतिमा: वेब एपको उत्पादन-तत्परता। योजनाबद्ध: अन-चेन प्रयोगशाला रजिस्ट्री र परीक्षण प्रमाणीकरण, प्रयोगशाला रिपोर्ट ग्रहणका लागि वास्तविक मेल-प्रदायक एडाप्टर, प्रोफाइलमा अन-चेन प्रमाणित एटेस्टेसन, गभर्नेन्स-नियन्त्रित उत्सर्जनसहितको **ट्रस्टलेस RewardVault** ([डिजाइन](docs/REWARD-VAULT-PLAN.md)), **सार्वजनिक टोकन बिक्री**, संस्थापक वितरणको भेस्टिङ अपडेट, र DEX लिक्विडिटी व्यवस्थापन (हाल रोकिएको — यसका लागि मेननेट टोकन परिनियोजन चाहिन्छ)। बहु-नेटवर्क विस्तार (Arbitrum, Avalanche र अन्य EVM चेनहरू) परीक्षण सञ्जाल बलियो भएपछि हुन्छ।

## सुरु गर्ने तरिका (विकासकर्ताहरू)

आवश्यकता: **Node.js 20+** र npm 10.x।

```bash
# Clone and install all workspaces
git clone https://github.com/Lilit-Moonlit/Evolve.git
cd Evolve
npm install

# Web app (Vite dev server on http://localhost:3000)
cd apps/web
npm run dev
npm test                # vitest suite

# Smart contracts
cd packages/contracts
npm run compile         # hardhat compile
npm test                # hardhat test suite
npm run deploy:local    # deploy all contracts to an in-process Hardhat network
```
