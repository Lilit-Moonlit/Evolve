# EVOLVE

**डेटिङ, गर्भधारण र स्वास्थ्य प्रमाणीकरण — पूर्वनिर्धारित रूपमा निजी, जहाँ आवश्यक छ त्यहाँ प्रमाणित।**

EVOLVE खुला स्रोत, विकेन्द्रीकृत प्लेटफर्म हो जुन प्रमाणित गर्न सकिने घनिष्ठ सम्बन्धहरूका लागि हो: डेटिङ, गर्भधारण र गुमनाम STD/DNA अनुकूलता। तपाईं आफ्नै क्रिप्टो वालेटबाट साइन इन गर्नुहुन्छ (Sign-In with Ethereum) — फोन नम्बर होइन, इमेल होइन, KYC होइन — र अन-चेन DNA प्रतिबद्धतामार्फत आफ्नो खाता पुनःप्राप्त गर्न सक्नुहुन्छ। स्वास्थ्य डेटा तपाईंकै रहन्छ: प्रयोगशाला परिणामहरू स्वचालित रूपमा पढिन्छन्, व्यक्तिगत रोगजनकको अवस्था कसैलाई पनि **कहिल्यै पनि** देखाइँदैन, र म्याचिङ केवल गुमनाम अनुकूलता निर्णयहरूमा आधारित हुन्छ (Safe / Compatible / Caution / Risk)। च्याट libp2p र Nostr मार्फत पियर-टु-पियर चल्छ, सुविधाका लागि HTTP फलब्याकसहित, र एपमा हल्का "Safety Mode" सार्वजनिक अगाडिको सतहसँगै STD परीक्षण मूल्याङ्कनका लागि स्वतन्त्र Companion Mode पनि छ।

> **स्थिति: प्रारम्भिक अल्फा।** EVOLVE सक्रिय विकासको क्रममा छ र यो अझै पूर्ण उत्पादन होइन।
> स्मार्ट कन्ट्र्याक्टहरू **केवल Ethereum Sepolia टेस्टनेटमा** मात्र डिप्लोय गरिएका छन्।
> **कुनै मेननेट डिप्लोयमेन्ट छैन, DEX छैन, लिक्विडिटी छैन, र सार्वजनिक टोकन बिक्री छैन** — र कुनै पनि वाचा गरिएको छैन।
> सुविधाहरू कुनै पनि समयमा परिवर्तन वा बिग्रन सक्छन्। यहाँको कुनै पनि कुरा वित्तीय सल्लाह वा लगानी प्रस्ताव होइन।

## के र किन

परम्परागत डेटिङ प्लेटफर्महरूले तपाईंलाई आफ्नो फोन नम्बर, इमेल, फोटो र घनिष्ठ स्वास्थ्य विवरणहरू केन्द्रीय डेटाबेसमा बुझाउन आग्रह गर्छन्। EVOLVE विपरीत परिकल्पनाबाट सुरु हुन्छ: पूर्वनिर्धारित रूपमा गोपनीयता, आत्म-संरक्षण, र कुनै केन्द्रीय असफलता बिन्दु नहुनु। मुख्य मूल्यहरू:

- **पूर्वनिर्धारित रूपमा गोपनीयता** — स्वास्थ्य डेटा कहिल्यै खुलासा गरिँदैन; केवल गुमनाम निर्णयहरू।
- **प्रतिबन्ध प्रतिरोध** — P2P-प्रथम मेसेजिङ, विकेन्द्रीकृत भण्डारण (IPFS / Arweave), बहु-सञ्जाल डिजाइन, हार्डकोडेड डोमेनहरू छैनन्।
- **आत्म-संरक्षित पहिचान** — तपाईंको वालेट नै तपाईंको लगइन हो; इमेल/फोनको सट्टा DNA-आधारित पुनःप्राप्ति।
- **KYC ढोका छैन** — प्लेटफर्म प्रयोग गर्न सरकारी परिचयपत्र, फोन वा इमेल आवश्यक पर्दैन।

पूर्ण तर्क [docs/WHAT-AND-WHY.md](docs/WHAT-AND-WHY.md) (अंग्रेजीमा) मा पढ्नुहोस्।

## मुख्य सुविधाहरू

### पहिचान र गोपनीयता

- **SIWE वालेट लगइन** (MetaMask र अन्य EVM वालेटहरू) — सेन्सरसिप-प्रतिरोधी आपतकालीन निकास।
- **DNA खाता पुनःप्राप्ति** — तपाईंको DNA परीक्षण परिणाम ह्यास गरिन्छ (SHA-256, `bytes32` का रूपमा अन-चेन प्रतिबद्ध) र फोन वा इमेलबिना नै पहुँ पुनःस्थापित गर्न सक्छ।
- **खाता एब्स्ट्र्याक्शन (ERC-4337)** — ग्यासरहित अनबोर्डिङका लागि स्मार्ट खाता र पेमास्टर; SIWE सधैं उपलब्ध रहन्छ।

### गुमनाम स्वास्थ्य अनुकूलता

- STD परीक्षण परिणामहरू कच्चा पाठ वा PDF का रूपमा अपलोड गर्नुहोस् (स्क्यान गरिएका पृष्ठहरूका लागि OCR फलब्याकसहित पाठ-तह निकास)।
- पार्सरले ८ रोगजनकहरू पहिचान गर्छ: HIV-1/2, सिफिलिस, क्लामाइडिया, गोनोरिया, HSV-1, HSV-2, हेपाटाइटिस B, हेपाटाइटिस C (अंग्रेजी, युक्रेनियन र रूसी रिपोर्ट ढाँचाहरू)।
- **व्यक्तिगत रोगजनक अवस्था अन्य प्रयोगकर्ताहरूलाई कहिल्यै देखाइँदैन।** प्रोफाइलहरूमा केवल गुमनाम निर्णय देखिन्छ: **Safe / Compatible / Caution / Risk**।
- अन-चेन DNA प्रमाणीकरण अभिलेखहरू (`DNAVerification.sol`) ले पुनःप्राप्ति र प्रमाणीकरण प्रवाहहरूलाई बल दिन्छ।

### प्रोफाइल, खोज र सञ्चार

- खोज फिल्टरहरू: "तपाईं के खोज्दै हुनुहुन्छ" (डेटिङ / गर्भधारण / बहुपति गर्भधारण / STD परीक्षण), "तपाईं कसलाई खोज्दै हुनुहुन्छ" (पुरुष, महिला, जोडीहरू), क्यास्केडिङ देश → सहर चयनहरू, देश-अनुसार सूचीसहित "तपाईंको देशमा आउन सक्छ", छालाको रङ, परीक्षण प्राथमिकता, केवल STD-अनुकूल।
- अनबोर्डिङ विजार्ड: उमेर (लुकाउन सकिने), भाषाहरू, बायो, फोटो।
- **फोटो गोपनीयता**: फोटोहरू पूर्वनिर्धारित रूपमा धमिलो हुन्छन्; मालिकले १५-सेकेन्ड वा स्थायी दृश्यहरू प्रदान गर्छ, पहलकदमी लिएर वा अनुरोधमा। हेर्न निःशुल्क छ।
- libp2p (gossipsub) + Nostr मार्फत **P2P च्याट**, HTTP API फलब्याकसहित।

### गर्भधारण मोडहरू

- **मोड २ — Pregnancy Bond**: एक महिलाले bond सिर्जना गर्छिन्, एक पुरुषले EVOLVE स्टेक गर्छ (हालको टेस्टनेट बिल्डमा ≥ १००), दुवै पुष्टि गर्छन्; पुष्टि भएको गर्भावस्था र पितृत्वपछि, स्टेक महिलालाई स्थानान्तरण हुन्छ।
- **मोड ३ — Cryptic Choice**: एक महिलाले ४८-घण्टाको सेसन खोल्छिन्, पुरुषहरू स्टेक गरेर सामेल हुन्छन्; उनले पिता छान्छिन् — उसको स्टेक फिर्ता हुन्छ, बाँकीहरू विभाजन गर्छन्: ९०% उनलाई / १०% छानिएका पितालाई।

### प्रयोगशालाहरू र प्रमाणीकरण

- **प्रयोगशाला साझेदार प्रवाह**: प्रयोगशालाहरू साझेदारका रूपमा दर्ता हुन्छन्, QR कोड र अनुहार मिलानबाट बिरामीहरू प्रमाणित गर्छन्, र STD रिपोर्टहरू संलग्न गर्छन् (OCR निकाससहितका PDF/पाठ)।
- **Companion Mode**: डेटिङ प्लेटफर्ममा सामेल नभई STD परीक्षण परिणामहरू मूल्याङ्कन गर्ने स्वतन्त्र प्रवाह।
- **Safety Mode** (`VITE_PRODUCT_MODE=safety`): सीमित सार्वजनिक अगाडिको सतह (STD स्थिति, सार्वजनिक प्रोफाइल लिंकहरू, अनुकूलता जाँचहरू) जुन क्षेत्राधिकार वा एप स्टोरमा डेटिङ/गर्भधारण सुविधाहरू प्रतिबन्धित भए पनि काम गिरहन्छ।

### EVOLVE टोकन (केवल टेस्टनेट)

- ERC-20, अधिकतम आपूर्ति ८,०००,०००,००० EVOLVE, एडमिन कार्यहरू ४८-घण्टाको TimelockController ले नियन्त्रित।
- **इमोजी उपहार अर्थतन्त्र**: एउटा उपहारको मूल्य १ EVOLVE, जुन विद्यमान उपहार मालिकहरूबीच समानुपातिक रूपमा विभाजित हुन्छ — धारकहरूका लागि स्थायी राजस्व मोडेल; उपहारहरू स्थानान्तरणीय छन्।
- **EvolveFund**: पुरुष स्टेकिङ (न्यूनतम १५ EVOLVE, ३०-दिने लक) जुन गभर्नेन्स वजनमा गणना हुन्छ; महिलाहरू आफ्नो वालेट ब्यालेन्स प्रयोग गर्छन्।
- **प्रमाणीकरण पुरस्कारहरू**: STD/DNA प्रमाणीकरणमा प्रमाणित प्रयोगकर्तालाई १ EVOLVE र पुष्टि गर्ने प्रयोगशालालाई १ EVOLVE (साथै दर-सीमित टेस्ट फौसेट)।
- गभर्नेन्स मतदान वजनले पुनरावर्ती प्रतिष्ठा (८ मत, गहिराइ ३), सन्तान/पितृत्व हिस्सा, र स्टेक गरिएको वा राखिएको EVOLVE संयोजन गर्छ।
- भविष्यका बहु-श्रृंखला EVOLVE स्थानान्तरणहरूका लागि **LayerZero OFT** एकीकरण (निर्भरताहरू तयार छन्; Sepolia बाहेक अझै केही डिप्लोय गरिएको छैन)।

### प्लेटफर्म

- वेब एप (PWA-इन्स्टलयोग्य) र Expo/React Native मोबाइल एप।
- इन्टरफेस **३४ भाषाहरूमा** अनुवादित।
- बहु-सञ्जाल तयार: १८ EVM सञ्जाल विन्यासहरू (Arbitrum र Avalanche योजनाबद्ध प्राथमिक L2 हुन् — **अझै डिप्लोय गरिएका छैनन्**)।

## आर्किटेक्चर र प्रविधि स्ट्याक

npm workspaces + Turborepo ले व्यवस्थापित Monorepo:

```
apps/
  web/          # Vite + React + TypeScript (main web app, i18next, Prisma)
  mobile/       # Expo + React Native
packages/
  config/       # Feature flags & dynamic remote configuration
  contracts/    # Solidity 0.8.24, Hardhat, Ignition, OpenZeppelin, LayerZero
  core/         # Shared types, utilities, middleware, web3
  matching/     # Matching algorithms, filters, ranking
  p2p/          # libp2p (gossipsub) + Nostr networking
  storage/      # IPFS, Arweave, Lit Protocol
docs/           # Architecture, tokenomics, roadmap, FAQ
```

मुख्य स्मार्ट कन्ट्र्याक्टहरू: `EVOLVE.sol` (ERC-20), `ProfileNFT.sol` (ERC-721), `TrustScore.sol`, `Voting.sol`, `Evolve2Earn.sol` (इमोजी उपहार + पुरस्कार), `Governance.sol`, `BondManager.sol` (मोड २ र ३), `EvolveFund.sol`, `VerificationRegistry.sol`, `DNAVerification.sol`, ERC-4337 `SmartAccountFactory` + `Paymaster`, र OpenZeppelin `TimelockController`।

## सुरु गर्ने तरिका (विकासकर्ताहरू)

आवश्यकता: **Node.js 20+** र npm 10.x।

```bash
# Clone and install all workspaces
git clone https://github.com/Lilit-Moonlit/Evolve.git
cd Evolve
npm install

# Web app (Vite dev server on http://localhost:3000)
cd apps/web
npm run dev
npm test                # vitest suite

# Smart contracts
cd packages/contracts
npm run compile         # hardhat compile
npm test                # hardhat test suite
npm run deploy:local    # deploy all contracts to an in-process Hardhat network
```
